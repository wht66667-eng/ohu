# 哦狐校园地图与校园圈 1.2.133 交付说明

构建版本：1.2.133（构建号 133）  
构建范围：学生端、管理端 Android APK；学生端、管理端 iOS 未签名 IPA。  
本次没有发布热更新、应用商店版本或云端数据库变更。

## 本版内容

- 学生端新增校园地图与动态列表入口，可按学校、校区查看公开动态。
- 登录用户可以发布文字和图片，发出前明确提示公开范围；默认用“校园用户”展示，昵称和头像需要主动勾选才会公开。新动态经管理员审核后展示。
- 动态支持点赞、评论、举报；举报可由管理员隐藏原文。
- 管理端内容工作台新增校园地图审核、底图样式地址、校区和地点录入。
- “定位到我”只在用户主动点击后调用系统定位，位置仅用于当前地图，不上传。
- 原课表、账号、朋友圈和提醒数据未迁移或删除。

## 启用地图前的云端步骤

当前没有经核验的地图样式、校园瓦片、校区边界和 POI 坐标，因此新页面会如实显示“底图尚未配置”，动态列表和发布审核仍可在数据库迁移后使用。不要把参考图里的外校坐标当成连云港坐标。

1. 先审核 `docs/sql/campus-map-132.sql`，在正确的 CloudBase 环境执行。此脚本只新增校园目录、地点、动态、点赞和评论表；当前没有在线执行。
2. 在管理员“内容管理 → 校园地图”中，为对应学校填写已验收且允许使用的 HTTPS MapLibre 样式地址。
3. 添加经过来源、坐标系、位置和授权核验的真实校区及地点。PMTiles/COS 需要支持 Range 请求及应用所需的跨域访问。
4. 用游客、学生、管理员账号分别检查公开范围、审核、举报、照片、互动和坐标准确性，再考虑发布云端数据。

## 安装包

Android 两个 APK 使用与 1.2.131 相同的正式发布证书，包名保持独立，可覆盖安装对应壳。文件名和 SHA-256 以同目录 `哦狐-1.2.133-APK校验.json` 为准。

两个 iOS IPA 由 GitHub Actions 使用 Xcode 26 / iOS 26 SDK 编译，**未签名，不能直接安装**。在 Windows 上可用 Sideloadly 和自己的 Apple ID 签名后安装；免费 Apple ID 签名通常需要每 7 天续签。构建成功和签名安装是两个步骤。

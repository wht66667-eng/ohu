## 本次优化

- 课表：游客可以浏览；绑定教务账号、调整课程设置和导出等操作先走应用手机号登录，登录后继续原操作，关闭登录弹层不会自动进入教务登录。保留江苏海洋大学原查询方式，其他学校的未完成草稿仍未发布。
- 账号隔离：教务及校园账号按应用真实用户、当前会话分别保存。切换账号、退出、同账号重新登录后，旧请求不能回填凭据。旧版设备共用凭据保留但不自动归属当前用户，需要本人重新输入，避免串号。记住密码关闭时保持关闭。
- 课程提醒：系统重启、应用覆盖升级和精确闹钟权限恢复后重新排好已保存的有效提醒。保留铃声、震动、系统闹钟开关、所属账号及超过原定时间 30 分钟丢弃规则。自动恢复和权限检查尊重用户关闭“提醒守护”的选择。
- 管理端：切换举报分类时立即移除上一分类结果，迟到响应不会覆盖新列表；账号或权限变化会清理旧页面状态。操作中防止重复点击，失败后可重试。封禁及解封改为一个数据库事务，账号状态和账户限制一起成功或一起回滚，返回结果必须匹配目标账号和用户。
- 好友确认：只能由收到申请的人处理未决申请，不能改写申请双方。通过申请和建立好友关系在同一事务完成，客户端不能任意伪造关系。保留旧客户端的兼容路径，不清洗或删除历史业务数据。
- 下载入口：分享页、旧下载 JSON 和应用更新入口统一从已核验学生 APK 生成。断网仍可下载当前页面已核验的版本，旧更新清单不能将页面降回旧包。管理端 APK 不会被误当成学生端下载。
- 保留快递七个平台入口、单号查询、朋友圈发布和查看，以及学生／管理端独立打包。

## 云端变更与验证边界

好友授权 SQL 和管理账号事务 SQL 已在现有云环境应用，并核对线上函数体、策略及执行权限。变更没有批量重写账号、课表或历史好友数据。隔离 PostgreSQL 测试使用 PGlite 18.6；线上为 PostgreSQL 17.10，生产复核检查的是实际部署定义与权限，不是替代真实用户进行操作。

没有连接测试手机，因此未重新实测锁屏、划掉最近任务后的到点送达或真实铃声震动。带登录身份的浏览器场景使用合成账号和隔离接口，未发送短信、发布动态、上传图片或封禁真实用户，也没有真实学校账号验收。没有接入新的厂商云推送；管理工作提醒仍需应用在线。朋友圈图片仍使用原公共存储，直链私密性未在本轮改变。

电脑网页仍使用腾讯云默认测试域名，首次打开可能出现平台访问提示。线上浏览器验收使用 Edge，实际点击平台“确定访问”进入；没有改写线上响应或移除提示。自定义域名尚未配置。

五条静态安全警告分别为：两个测试合成凭据被模式扫描命中、非 Git 工作区无法检查已跟踪文件、Dockerfile 未声明运行时资源限制、遗留 old-cf 目录仍有 CORS 通配配置。未修改扫描器掩盖警告，也未在本轮调整遗留服务的部署。

# 哦狐插件创作者工作流

适用版本：哦狐静态内置插件 v1
入口：App「我的 → 设置 → 哦狐科技」

## 先理解上架方式

当前插件市场不运行用户上传代码，也没有 APK 内动态下载插件能力。创作者提交 GitHub 仓库和说明后，管理员进行审核；通过的模块由哦狐维护者纳入源码、静态注册、随 Web／APK 构建并发布。第三方项目可以作为带“非官方”标记的外部参考链接展示，但外部 APK、脚本或网页不会因此变成哦狐内的插件。

## 创作者流程

1. **选一个小而明确的功能**：优先单一用途、无账号或隐私数据依赖的模块。自动刷课、代答、伪造学习记录、规避学校平台规则不予接入。
2. **建立公开仓库**：包含源代码、README、许可证、依赖说明、功能截图和运行／构建步骤。不要提交密钥、账号密码、签名文件或真实个人数据。
3. **填写插件提案**：按下方模板说明 ID、版本、用途、路由、所需权限、数据读写、网络访问、依赖、来源和兼容范围。若基于其他开源项目，固定仓库和 commit，并逐项核对应用代码、素材、字体和数据集各自的许可。
4. **提交审核**：在哦狐「哦狐科技」打开“插件作者工作流”，点击“提交插件接入方案”，粘贴仓库链接和提案。提交表示进入评估，不代表已经批准、上架或安装。
5. **管理员审核**：检查仓库来源、许可证、依赖与构建脚本、隐私与网络行为、权限最小化、移动端可访问性、校园适用性及基本运行结果。审核结果通过哦狐现有联系渠道回复。
6. **维护者接入**：审核通过后，维护者把经过审查的实现作为本地 TypeScript／React 模块加入 `src/plugins/builtin/`，在 `plugin-manifest.ts` 与 `registry.ts` 静态登记，并展示作者／来源／许可证信息。
7. **构建与发布**：模块随哦狐 Web／APK 新版一起发布。用户更新哦狐后，在插件市场启用。没有新版发布前，不会在用户设备中生效。
8. **维护与下架**：作者在原仓库持续维护并报告漏洞／许可变化；维护者复核版本与依赖，必要时暂停入口并随新版修复或移除。

## 提案模板

```yaml
id: example-campus-tool       # 小写 kebab-case，唯一且发布后不复用
version: 0.1.0                # SemVer
name: 示例小工具
category: 学习效率            # 学习效率 / 校园生活 / 趣味探索
summary: 一句话描述用户能做什么
entryPath: /已有哦狐路由      # 必须是已经登记的哦狐路由
permissions: []               # 只从 OhUPluginPermission 白名单中选择
author: 作者昵称或组织
sourceRepository: https://github.com/owner/repo
sourceCommit: 固定 commit SHA
license: MIT                  # 必须与仓库 LICENSE 和实际素材一致
data: 不收集任何用户数据
network: 无
dependencies: []
testedOn: Android WebView / Chrome 等实际检查范围
checks: 已实际完成的构建、手动检查或自动化检查
```

该 YAML 是提案格式，不是 APK 可加载的插件包。正式清单接口以 `src/plugins/plugin-manifest.ts` 为准；未知字段不能自行要求 App 读取。

## 开源参考项目展示规则

下列项目在商城以“非官方开源参考”链接呈现；哦狐内的趣味小模块由本项目独立编写，不复制其代码、设计素材或数据集：

| 项目 | 仓库许可（以具体文件为准） | 商城处理 |
|---|---|---|
| [anois/tarot](https://github.com/anois/tarot) | 仓库标示 MIT；牌面、字体、含义数据可能有各自许可 | 参考隐私优先的塔罗体验；不复用牌面图片 |
| [fortune-org/fortune-platform](https://github.com/fortune-org/fortune-platform) | GitHub 仓库标示 MIT | 参考本地趣味占卜方向；不复制其代码或计算数据 |
| [heshengtao/exameow](https://github.com/heshengtao/exameow) | GitHub 仓库标示 Apache-2.0 | 独立学习应用外链，不嵌入哦狐 APK |
| [ankidroid/Anki-Android](https://github.com/ankidroid/Anki-Android) | GitHub 仓库标示 GPL-3.0，注意仓库内可能另含其他许可组件 | 独立 Android 应用外链，不复制／嵌入其实现 |

仓库内容、许可证、构建要求和移动端兼容性可能变化；实际接入前必须再次核对具体版本及全部素材许可。外链不构成哦狐背书。

## 趣味占卜模块的产品边界

- 页面明确标注“非官方 · 趣味内容”，并展示开源灵感来源与许可说明。
- 只作为娱乐或自我反思提示，不声称预测事实，不提供医疗、法律、财务、考试结果或人身安全决策建议。
- 生日数字功能在本机页面状态中临时计算；禁止保存／上传生日。星座功能不需要出生日期、时间或地点。
- 不使用来源不明的塔罗牌图、字体或牌义数据库；本版以文字提示呈现。
- 用户评分仍是本设备、本账号的私有评分，不显示虚假的公开平均分。

## 维护者接入检查表

- [ ] 确认唯一 ID、版本和已存在路由。
- [ ] 审阅源码、依赖、安装脚本和网络访问；拒绝 eval、远程脚本与动态 URL 导入。
- [ ] 核对代码、图像、字体、文案和数据集的独立许可要求。
- [ ] 只申请最小白名单权限；不新增权限前先评估数据流与用户提示。
- [ ] 插件声明作者、官方状态、外部来源和许可证；外部内容始终标“非官方”。
- [ ] 将模块显式加入静态注册表，验证禁用／启用行为与身份数据边界。
- [ ] 实际记录类型检查、构建、手机窄屏和无障碍检查结果；未执行项明确标注。
- [ ] 更新 `docs/product/哦狐_实际项目设计与实施方案.md` 的插件架构说明及实施台账。

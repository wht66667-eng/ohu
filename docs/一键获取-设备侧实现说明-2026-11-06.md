# 一键获取 · 设备侧实现说明（真机验证中）

> 日期：2026-11-06 · 工作区：哦狐 React + Capacitor 1.2.150
> 目标：不注册手机号，只用「学号 + 校园网(VPN)密码 + 统一认证密码」在设备内取数；
> 体测、PU、学习通各自登录一次后也能一键更新。

---

## 0. 一句话

新增原生 `CampusBridge` WebView 桥 + TypeScript 编排层：三输入自动走
**WebVPN → CAS → 正方（成绩/课表/考试）**；体测走独立账号；PU / 学习通走可见授权页；
全部数据落到本机「学号身份」下，不需要哦狐手机号账号。

---

## 1. 架构

```
React 页面 /study/oneclick
   │  src/lib/one-click.ts（阶段状态机、URL 契约、解析、落库）
   ▼
src/lib/campus-bridge.ts（Capacitor 插件封装）
   │
   ▼
CampusBridgePlugin.java（离屏 WebView + 可见登录层）
   │  只允许 jou.edu.cn / pocketuni.net / chaoxing.com
   ▼
WebVPN(58888) → CAS → 正方 / 体测 / 实践；PU / 超星为公网
```

**为什么必须在设备侧**：学校拒绝腾讯云出口 IP（实测 `/do-login` 被打回），
云端无法代登录；密码也不能进云端。原生桥只做「加载 / 执行 JS / 返回 URL」，
业务编排和解析都在 TypeScript，便于回归。

---

## 2. 登录链路（来自抓包契约）

```
WebVPN   GET  http://webvpn.jou.edu.cn:58888/login
         表单  #user_name / input[name=password] / button#login
         提交  /do-login（页面 JS 处理）

CAS      GET  /https/<casHex>/lyuapServer/login?service=https://zf.jou.edu.cn/login_cas.aspx
         表单  username / password / 登录

正方     GET  /https/<zfHex>/cas_verify.aspx        ← 用 ST 换会话
         GET  /https/<zfHex>/xs_main.aspx?xh=…       ← 登录态 + Referer
         GET  /xscj_gc2.aspx?xh=&xm=&gnmkdm=N121619  ← 成绩（需点「按学期查询」）
         GET  /xskbcx.aspx?xh=&gnmkdm=N121603        ← 课表（Table1 文本网格）
         GET  /xskscx.aspx?xh=&gnmkdm=N121604        ← 考试
```

失败兜底：自动提交后若 25 秒没有跳转，自动切换到可见页面让用户手动完成
（密码错、二次验证、验证码都走这条路），完成后继续后续步骤。

## 4. 学号本机身份

- uid：`local:zhd-<学号>`，写入 `ohu.local-identity.v1`。
- `qbank.captureQbankSession()` 在无手机号账号时退回该 uid，所有本机缓存
  （课表/成绩/考试/体测/PU/学习通）自动按学号隔离。
- 有手机号云端账号时云端 uid 优先，不覆盖；云端登出后仍保留学号身份。
- 云端功能（聊天/广场/题库）仍按原手机号账号，未改动；本次只取消「校园数据必须手机号登录」。

---

## 5. 密码规则（页面内已展示）

- **WebVPN 密码**：2023 级初始为身份证后八位；2024 级及以后为身份证后八位@Jou。
- **统一认证密码**：初始为 Jou@身份证后八位。
- **体测密码**：首次可尝试「姓名首字母大写_学号」（例：王昊天 2023120448 → WHT_2023120448）。
- 以上为学校初始规则；改过密码用新密码，忘记可在对应系统找回或咨询网络中心。

---

## 6. 安全

- 密码只在内存与页面脚本之间传递；不写 localStorage（除非用户勾选「记住密码」，
  用本机随机密钥加密）、不写日志、错误文案不回显。
- 插件只允许 `*.jou.edu.cn`、`*.pocketuni.net`、`*.chaoxing.com`；
  明文 HTTP 只对 `webvpn.jou.edu.cn` 与 `tice.jou.edu.cn` 放行（网络安全配置）。
- 只取本人数据，不做批量/共享。

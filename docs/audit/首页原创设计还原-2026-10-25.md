## 设计拆解

- 原图 863×1822，含手机边框与系统栏，内容宽约800px；按约2倍图稿还原为400 CSS px左右。
- 森林绿 #1f5b3a、暖象牙 #fff8eb、狐狸橙 #ff8a3d。首页局部映射既有语义变量，保留深色模式。
- 页面边距约14px；卡片圆角约18–22px；标题18–27px；正文12–15px。图稿无标尺和字体文件，以上为合理估算，未声称像素级自动比对。
- 首页内容滚动，底部五导航固定于手机壳；校区、设置、服务编辑使用既有 DialogLayer。
- 静态品牌横幅使用800×317原图裁片；任务右侧使用478×194原稿阅读场景。没有将整张UI截图设为背景。
- 10个功能图标裁至图形区域，圆角透明处理；5个标题图标用边缘连通去底色，保留封闭图形内部白色细节。所有来源坐标在 asset-provenance.json。

## 数据与权限

- 今日课从经过UID/学号/学期校验的本机快照读取；遵守法定假日与调课，不将未绑定/失败画成“今天没课”。下一课后最多显示两节真实后续课。
- 待办仍按当前UID过滤，读取失败可重试，提醒弹窗的延后、去重和账号切换防护保留。
- 今日任务卡展示最近待办；进度数字是全部已加载待办的完成数/总数，不冒充“今天到期”数量。
- 未读消息、校园动态、互助及闲置使用原有数据源；空、部分失败和加载反馈保留。
- 常用功能尊重当前账号在本机保存的1–6项选择；4–6项按图稿紧凑排布，320px时5–6项换行。没有把图中尚未接通的食堂点餐/校园卡/图书馆服务伪装为可用。
- 天气为现有海大周边天气，不声明随所选校区或GPS变化。

构建：`npm run build`。业务回归：`node --test tools/home-preferences.test.mjs tools/schedule-cache.test.mjs tools/ohhu-navigation.test.mjs tools/work-access-gate.test.mjs tools/boot.test.mjs tools/polling-hook.test.mjs tools/shell-badge.test.mjs`。

71项相关业务回归通过；生产构建通过。第一轮截图发现窄屏头像目标39px，已修为至少44px；原普通标题图标已替换为原稿裁切。Playwright最终验证通过15个状态、9种常用布局和5项点击；320/390/430无横向溢出，首页可见链接/按钮高度均至少44px，全部提取图片加载正常，0外网请求、0页面异常。深色小链接修复后对比度约9.21:1。第一轮与最终验证报告、顶部/底部、浅/深色截图位于 `.map-qa-output/home-brand/`。

原图没有可编辑图层和中文字体，标题使用系统中文粗体；不同设备字形与断行会有差异。真实课程/任务/动态内容长度及默认常用数量与设计稿演示数据不同。地图、课表与服务页本轮不继续重写；原生真机和安装包外观尚未验收。本轮未发布热更新、未覆盖已发布安装包，也未改线上数据。

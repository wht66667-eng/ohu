## 3. 全站统一的视觉规则

### 3.1 保留当前首页的设计语言

整体语气：友好、活泼、实用。森林绿组织信息，暖象牙白承载内容，狐狸橙强调状态与少量装饰。

| 语义 | 基准 |
|---|---|
| 主品牌色 | #1F5B3A |
| 品牌象牙白 | #FFF8EB |
| 当前首页页面底色 | #FFFAF0 |
| 当前首页卡片底色 | #FFFEFA |
| 强调色 | #FF8A3D |
| 当前首页主要文字 | #153D2C |
| 当前首页次要文字 | #616C62 |
| 边界与浅色背景 | 以现有首页语义变量为准 |
| 页面边距 | 14–16 CSS px |
| 普通卡片圆角 | 18–22px |
| 弹层圆角 | 约24px |
| 标题 | 页面24–28px、分组16–18px，按实际宽度缩放 |
| 正文 | 常规14–16px；高密度辅助信息12–13px |
| 点击区域 | 主要按钮与图标按钮至少44×44px |

尺寸属于实施基准，需要在真实页面截图中校正。参考长图中的10px级说明字不能机械缩放为正式阅读字号；重要课程、时间、地点、错误信息必须保持可读。

沿用系统中文字体及项目数字字体设置；未取得原稿字体文件之前，不声称标题字形完全一致。不把标题截成图片来模拟字体。

### 3.2 公共样式的整合方式

首页目前在 HomePage.module.css 内局部映射颜色。推广时，先将这些值整理到现有语义变量与组件变体中；逐页迁移，保证首页回归截图稳定。

不复制 V4/V7 整套全局 CSS，不同时保留两套互相覆盖的颜色系统。深色模式继续通过现有 theme 机制控制，插画边缘和文字对比度单独验收；不强制重置用户已有外观偏好。

### 3.3 插画、图标与抠图要求

1. 狐狸采用本次原稿的橙白脸、绿色服装和圆润描边语言。
2. 优先复用 public/brand/ohu-original 与 OhuArtwork 中已整理的原稿资源。
3. 新裁片只提取狐狸、图标或静态装饰；昵称、功能名、课程、倒计时、点赞数均由组件绘制。
4. 检查白边、文字残影、缺耳朵/缺尾巴、重复底色和缩放模糊。分别放在米白、白、深色背景上检查。
5. 图标透明边缘正确后再确定容器底色；不使用 multiply 混合模式掩盖未处理的白底。
6. 横幅、图标、头像预留尺寸或宽高比，图片加载不推动正文跳动。
7. 保留素材来源、裁切范围、尺寸和用途记录；同一素材只保留必要分辨率。

### 3.4 导航与登录

学生端继续使用：首页 / 服务 / 发布 / 广场 / 我的。保留当前首页的绿色中央发布按钮和底栏形态，并将统一外观推广到其他主页面。

课表参考图里的“课程”底栏只借鉴图形风格，不替换现有“服务”入口。地图从服务等现有入口进入，不新增第六个底部标签。

公开内容继续允许浏览；发布、私信、收藏、修改个人资料等功能沿用各自真实登录校验。哦狐账号登录与学校教务绑定是两个独立步骤，登录成功不冒充学校已经绑定。

## 4. 服务页：以原稿为主要还原页面

### 4.1 结构

从上到下：哦狐品牌与搜索、消息入口 → 校园狐狸横幅 → 最近使用 → 重点功能卡 → 分类服务。

最近使用由真实账号本机记录生成；不足六项时按实际数量排布，不能把图中的六个入口冒充最近使用记录。首页自定义常用功能保持原偏好。

重点功能采用原稿的狐狸插画卡，优先展示真实高频功能。建议四项为课表查询、成绩查询、番茄专注、校园卡；前三项接现有入口，校园卡显示未开放标识。最终仍以现有可用功能与用户偏好为依据。

### 4.2 分类方式

视觉上可参考原稿六个模块，但不为分类展示改动后端模型：

| 展示模块 | 对应现有内容 |
|---|---|
| 课业安排 | 课表、成绩、考试、待办、综测 |
| 英语学习 | 单词、题库、真题与已有练习 |
| 校园生活 | 附近美食、校园卡、班车、快递、运动 |
| 地图与打卡 | 地图、我的地点、打卡、图书馆座位 |

以 SERVICE_CATALOG 为真实入口清单，增加必要的展示分组映射；原来已实现的功能全部保留。原图中的论文润色、空教室等其他未接通能力，不自动新增成可用服务。

### 4.3 已确定的四项服务处理

| 入口 | 展示 | 点击行为 |
|---|---|---|
| 校园卡 | 保留图标与标题，附“暂未开放” | 说明尚未接通；不出现充值、余额、消费记录等假操作 |
| 校园班车 | 保留入口，附“暂未开放” | 说明尚未接通；不生成模拟时刻表或车辆位置 |

| 附近美食推荐 | 替换食堂点餐，使用餐具或美食图标 | 进入真实美食地点列表，可看图、查看详情、导航与打卡 |

三个未开放入口可点击说明，但必须从外观上与可用服务区分。现有快递身份码、待取包裹入口和单号查询全部保留。

### 4.4 附近美食的第一版范围

复用地图中真实的美食地点与已审核图片，不新增点餐、支付和商家订单系统。

用户允许定位后，可按实际坐标计算距离并排序；拒绝定位时，允许选择校园或地图范围，显示“当前范围美食”，不标虚假的“距你320m”。

只有确实取得的地点、图片、地址等字段才展示。没有真实来源的评分、营业时间、人均消费、销量和“热门”标签不生成。数据较少时明确显示少量结果和添加地点入口。

公共推荐使用允许公开的数据；本机私有地点只对所属账号展示。地点不足的问题与 UI 改造分别记录。

## 5. 课表：高还原时间轴，保留完整周视图

### 5.1 布局

采用原图的狐狸顶部装饰、七日日期条、今日标题、左侧时间轴和右侧课程卡片。狐狸插画不挤压课程名称和教室信息。

点击日期切换真实当天课程；前后周控制必须作用于真实教学周。保留本周课表网格、课程详情、学期与作息设置、调课与假期、重新同步和 ICS 导出入口。

课程卡片颜色按课程稳定分配；当前课程用绿色轮廓和状态标签突出，下一课程使用少量橙色提示。课程长名称允许换行，教师和教室不得与插画重叠。

### 5.2 真实状态

未绑定、未同步、缓存归属异常、同步失败、假期、无课和正常课程分别展示。失败不能转换成“今天没课”。

原图的“今日课程小结”由真实课表计算节数、已结束课程数和时长。没有签到/出勤数据时使用“已结束”，不把经过上课时间等同于用户完成学习。

午休分隔根据课程间隔或真实作息显示；重要考试提醒来自实际考试数据，不复制示例考试。

### 5.3 学校入口与提醒

江苏海洋大学继续使用现有内置同步。康达、师范、连职院、江苏财会等其他学校当前是官方查询指引，尚未接通个人课表同步时必须明确说明，不制作假登录成功状态。

课程与考试提醒已有时点、铃声、震动、通知权限、精确闹钟和后台限制相关能力。本轮主要改进设置层级与状态呈现，保留已有排程、账号隔离及超过30分钟的课程提醒不补发规则。

手机权限、应用内偏好、实际排程结果和设备实际响铃分别反馈；UI 改造不等于完成锁屏或划掉后台送达验证。

## 6. 地图：真实地理数据的手绘风与标准风

### 6.1 目标解释

用户需要的是“真实地图都画成手绘风”，不是将参考校园大图放大充当地图。

默认模式为“手绘地图”，另设“标准地图”切换。同一真实坐标对应同一地点，两种模式均可缩放、定位、筛选、查看地点、导航和打卡。覆盖连云港全域与已配置校园。

标准模式沿用当前真实底图方案，不自动引入新的收费地图服务。当前项目已经使用 MapLibre、OpenFreeMap 默认样式，并有连云港范围设置；不能再笼统写成“地图底图未配置”。

### 6.2 手绘风的实现路线

采用现有 MapLibre 渲染器，对真实矢量数据设置道路、建筑、水系、绿地、文字和地点图标样式。样式文件可以定义数据绘制内容、绘制顺序和外观，符合 [MapLibre 样式规范](https://maplibre.org/maplibre-style-spec/)。

建议视觉处理：

- 道路使用暖米白与柔和描边，保留真实道路连通关系。
- 绿地采用柔和绿色，可叠加轻纹理；树木装饰限制在绿地范围内。
- 水系使用低饱和蓝色，保持真实岸线。
- 建筑基于真实轮廓绘制暖色块与边线；具有可靠字段时再表现高度等细节。
- 地点使用原稿语言的独立图钉与标签，不把图钉烘焙到背景图中。
- 普通地名字体优先保证中文覆盖和清晰度；装饰字体只用于非关键品牌文字。

小比例尺优先显示城区、主干路和水系；放大后显示校园、建筑、步道及地点细节。外观覆盖整个范围，细节数量取决于真实瓦片提供的数据。

“每栋建筑都成为原稿那种独立透视插画”需要额外的实测建筑数据与插画生产，不在样式换肤时承诺自动完成。第一阶段的交付标准是地理准确、整体手绘语言统一，并保留真实交互。

### 6.3 切换要求

实现时优先让两套样式共享同一底图数据源；样式切换使用现有渲染器能力，参照 [MapLibre Map.setStyle](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/#setstyle)。

切换必须保留：中心点、缩放、方向、选中校园、分类、搜索结果、选中地点、当前位置与地点草稿。重新挂载样式时检查并恢复业务地点图层、图标和事件，避免重复监听或图钉消失。

样式加载失败时给出明确反馈，可回到可用的标准模式；不能悄悄换成静态图并继续显示“定位成功”。保留地图数据署名。

### 6.4 页面布局

顶部为紧凑品牌区与“校园 / 全城”范围；下面放搜索和分类。手绘/标准是另一个独立切换，不能与校园/全城混成同一概念。

地图是主要画布；“我的位置”和“添加地点”固定在容易触达的位置。地点详情使用底部面板，展示图片、名称、真实分类、位置、实际距离、审核状态和导航/打卡操作。

小屏上面板可收起，避免盖满地图；上拉详情和地图拖动需要区分手势。搜索、定位、添加地点均提供正常按钮，不依赖透明坐标热区。

分类以真实字段为准。美食、好玩、打卡可在现有数据上明确区分；学习、生活等分类只有存在相应地点数据与筛选映射时才作为可用筛选显示。

### 6.5 地点与高德导航闭环

保留：手机定位 → 可微调选点 → 图片与描述 → 保存本机地点 → 可选上传审核 → 审核后进入公开列表。

本地、待审核、已通过、未通过分别标识。本地图片与云端图片继续使用各自真实存储方式；待审核内容遵守所属账号的可见性。

导航继续优先尝试高德 App，失败时提供官方网页，并保留步行、骑行、驾车选择。沿用现有坐标转换规则，避免重复转换造成偏移。两种地图样式下的目标坐标必须一致。

## 7. 广场与朋友圈：使用 V7 外观，保留不同业务边界

### 7.1 广场

采用 V7 的标题与圆形操作、狐狸主题卡、快捷入口、发布提示框、分段切换和内容卡片。

手机使用单列信息流；正文、图片和互动为主要内容。上方横幅与插画遵循原稿比例，但不连续堆叠三块重复大横幅遮住第一条动态。

保留现有动态、大厅聊天、热榜及权限限制。卡片依次为头像与作者、时间与类别、正文、图片、互动与更多菜单；图片预留比例，点开可查看。

点赞必须调用真实逻辑并处理失败；评论、举报、删除、联系等动作使用原功能。参考中的数字和热门排序不能通过修改 DOM 冒充服务端结果。

### 7.2 朋友圈

沿用 V7 卡片与发布语言，但继续使用 Moments 的真实数据、图片规则、好友关系和可见范围。保留现有最多九图等实际能力，不降级成参考中的单图演示表单。

广场公开动态、朋友圈、地图校园动态是不同数据模型；只统一视觉，不合并接口、审核、发布范围或计数。

## 9. 我的与设置：采用 V7 身份卡与分组列表

“我的”从上到下为：标题与设置 → 身份卡 → 四项概览入口 → 小型狐狸阅读卡 → 学习与发布 → 同学联系 → 消息与设置 → 帮助。

身份卡使用真实头像与昵称；学校、管理员身份等只显示已经确认的资料。游客提供登录入口，学校绑定单独进入课表或校园账号页。

课表、打卡、待办、未读消息四项入口可借用 V7 排布。只有能可靠读取的数据才显示数字；加载中、读取失败和真实零值分别处理，不把原型“2/5”等数字保留下来。

收藏、我的发布、待办、朋友圈、通讯录、校园账号、通知、设置、联系管理员等原入口保留；学生账号不能因视觉改版看到无权限的管理能力。

设置按外观、账号与校园绑定、通知与提醒、手机权限、隐私、关于与更新组织。保留现有 section 链接与端类型判断，通知中心和通知权限设置进入不同位置。

## 12. 轻快适度的动效标准

| 操作 | 建议反馈 |
|---|---|
| 按压 | 约120–180ms的小幅缩放或底色变化 |
| 筛选与分段 | 约160–240ms的选中层移动与颜色变化 |
| 弹层 | 约220–320ms进入/退出，避免明显弹跳 |
| 点赞 | 约200–300ms图标放大回落，成功/回滚与请求一致 |
| 加载与空状态 | 局部骨架，狐狸主要静态；慢请求显示进行中说明 |
| 主题 | 短过渡，保持内容和当前位置 |
| 地图样式 | 显示切换状态，镜头不飞回初始位置 |

统一扩展现有动画参数。普通页面不添加持续摇晃、全屏粒子、强视差、摇手机触发或自动翻转卡片。拖拽、滑动等可作为后续增强，不是本次必须新增的手势。

减少动态时取消非必要位移、过冲与循环动画，保留状态变化和可读反馈。不能仅因请求超过三秒就宣布失败。

## 14. 验收清单

### 视觉

- 以390px左右手机视口作为主要对照，并检查320/430px和较宽浏览器窗口。
- 对照图先比较分区、比例、插画位置与留白，再校正图标、文字、圆角和边缘。
- 首页课程、任务、常用偏好和底栏保持稳定；实际文案长度变化允许内容高度自适应。
- 无白块遮盖、旧文字残影、重复图标、破图、横向溢出或底部遮挡。
- 系统状态栏、手机边框不作为页面图片绘制。

### 功能与状态

每个相关页面检查：游客、已登录、加载、真实内容、空数据、慢请求、失败与重试、账号切换。表单额外检查校验、上传失败、重复提交、取消与关闭后恢复。

- 三个未开放服务只能显示说明；附近美食进入真实数据。
- 原有搜索、筛选、收藏、消息、发布、学习和权限行为保持可用。
- 广场、朋友圈、地图动态分别验证可见范围与审核。
- 手绘/标准切换前后的同一地点坐标、距离、选中状态一致。
- 定位拒绝、超时、样式失败、地点为空和本地图片缺失均可理解并恢复。
- 通知与铃声震动必须另做真机验证；浏览器按钮可点不等于锁屏提醒已验收。
- 外部 App 导航分别检查安装/未安装状态与网页回退。

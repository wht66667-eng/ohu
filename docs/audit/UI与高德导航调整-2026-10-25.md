# 哦狐 UI 与高德导航调整

日期：2026-10-25。模式：DESIGN，React / Capacitor WebView，沿用 CSS Modules 与现有主题令牌。

## 本轮已修改

- 服务：双列紧凑目录、线性图标、可换行分类，加入真实地图打卡入口。
- 地图：收起大介绍区、范围与区域双列、全部常用动作可见，地点详情适配主题颜色。
- 广场：标题与动作分行，增加朋友圈直达，发布为主操作、地图与朋友圈为次操作。
- 公共组件：发布统一绿色；页头、空状态、消息页、个人页与管理工作台控件统一间距与触控尺寸。
- 高德：安卓安装包内先调用官方 App URI，失败回退官方网页；网页用户继续使用 callnative=1 官方入口，保留仅网页选择。步行、骑行、驾车及 WGS84 转换参数分别验证。

## 验证记录

- TypeScript 检查与生产构建通过。
- 63 项发布回归测试通过。
- 14 项地图测试通过，包括新增原生高德 URL 测试。
- 浏览器实际查看服务、地图、广场、个人页；服务搜索、游客快递登录拦截正常；地图显示 13 个云端候选地点。
- 预览为桌面浏览器手机布局，不等同真机验收。已安装/未安装高德场景尚未真机测试。
- iOS 现有独立工程未发现 AppProbe 原生桥，iOS 直接唤起仍需补桥接并重新构建验证。当前共享前端调用失败时回退网页。
- 管理端登录后的列表、深色主题及全部二级页面尚未逐页视觉验收。

## 交付范围

本轮修改本地源码与预览，不发布热更新、不覆盖已发布的 1.2.135 安装包。下一轮发布需使用新版本号；iOS 同步应逐文件保留原有专用提醒补丁。

# 地图照片、定位、导航与云端接入

日期：2026-10-23。项目：哦狐。

## 本轮完成

- 地点可添加最多 3 张照片，支持相册与拍照入口、移除、缩略图和大图查看。保存前压缩并检查大小。
- 仅本机保存时，照片使用 IndexedDB 按账号隔离；用户选择提交审核后，才调用现有图片上传服务，将照片地址与地点一起提交。
- “使用我的位置”获取前台位置并填入地点坐标，显示精度；也可在地图上选点或手动填写坐标。拒绝权限、超时及连云港范围外都有提示，不申请后台定位。
- 地点详情新增高德步行、骑行、驾车入口，以及仅打开网页版的备用入口。游客可浏览，点击导航需先登录。
- 使用高德官方 HTTPS URI，传入 WGS84 目的地坐标及名称，起点交由高德获取或填写。Android 使用已有原生打开链接能力；网页由系统浏览器处理。
- 审核通过时保留照片和备注。同名地点不再静默丢弃照片后显示审核成功，而是提示管理员核对并继续处理。
- 修复游客公开评论读取时请求了无权访问的账号字段，以及初次恢复会话导致的“账号已切换”误提示；旧页面请求结果不得覆盖新账号或新范围。

## 验证结果

- 13 项自动检查全部通过：导航参数与编码、游客评论字段权限、同名审批、学生提交、其他账号隔离、管理员通过/驳回、打卡可见性、伪造身份拦截、迁移重跑、定位错误与本地地点隔离。
- `npm run build` 通过，包括 TypeScript 检查和前端正式构建。
- 浏览器隔离验收：学生甲添加照片与虚拟定位 → 保存本机 → 提交 → 管理员查看照片并通过 → 学生乙看到共享地点和照片。
- 浏览器验证定位拒绝及异地提示；真实云端页面正常展示地点，游客点击导航出现登录界面。
- 正式云端匿名公开读取和 authenticated 权限下 SQL 规划检查通过。

## 尚需实机验收

- 本轮没有真实学生登录后向正式图片桶上传照片，也没有真实管理员的完整端到端云端审批；隔离环境通过不等于这一步已完成。
- 本轮没有实际 Android / iPhone 的 GPS、相机及高德安装/未安装两种状态验收。电脑访问高德路线页时出现连接关闭，未确认真实路线页面加载成功。
- 高德接口只在移动端尝试唤起客户端；电脑端骑行能力受高德页面限制。备用网页版入口可避免反复尝试唤起，仍依赖高德网络服务可用。
- 13 个地点为公开地图候选位置，需要管理员继续核验现场入口。五所学校的具体校区坐标未在本轮臆造或补入。

# 哦狐 1.2.135 发布与安装说明

发布日期：2026-10-23。

## 已发布

安卓学生端与管理端更新清单、两端热更新和电脑网页均已上线。

- 已安装 1.2.134 或以上安卓包：打开应用，在“设置 → 关于与更新”检查界面更新，按提示完成重载。
- 已安装 1.2.133 或更旧安卓包：先安装本文件夹中的同端 1.2.135 APK。热更新最低原生构建号为 134。
- 安卓包沿用原签名；学生端与管理端包名独立。正常覆盖安装，不要先卸载旧应用，以免清除本机打卡点及其他本地数据。
- iOS 继续使用独立编译包，本次不启用 iOS 热更新。

## 本轮功能

地点最多 3 张照片，相册或拍照选择；手机前台定位及地图选点；高德步行、骑行、驾车入口和网页备用入口；本地地点提交后由管理员审核，审核通过保留照片和备注。地图云端已接通，13 个公开地图候选地点可用。

## iPhone 个人测试安装

IPA 已由 macOS / Xcode 实际编译成功，但未签名，不能直接点击安装。

1. 使用 [Sideloadly 官方工具](https://sideloadly.io/)，按官网要求准备 Windows 驱动和依赖。
2. USB 连接并解锁自己的 iPhone，确认手机信任电脑。
3. 在工具中选择学生端 IPA，使用自己的 Apple ID 完成个人签名并安装；密码及验证码自行输入，不发送到聊天或写进文档。
4. 根据 iPhone 实际提示完成开发者信任或开发者模式设置。
5. 覆盖后续版本时保持相同 Apple ID 和实际安装标识。免费签名有效期与限制以 Apple 和签名工具当时提示为准。

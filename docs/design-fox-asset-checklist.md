# 小狐狸美术资源补齐清单

> 版本：1.2.35 之后
> 日期：2026-09-29
> 结论一句话：**不需要重画狐狸，需要「抠干净」+「补几个姿态」+「补透明背景层」。**

---

## 0. 现在的核心问题（实测）

我把现有资产按 App 实际用法（圆形裁切 + 玻璃底座）渲染了一遍，三个硬伤：

| 问题 | 实测证据 | 视觉后果 |
|---|---|---|
| **① 每张图带不同背景** | `icon-streak_7` 是蓝天海面、`icon-away_20` 是紫夜下雨、`icon-away_30` 是火海 | 并排/切换时**色调乱跳**，像三只不同的狐狸 |
| **② 不是 1:1，圆形裁切会切头** | 采样四角全是实色（`(252,184,46,255)` 等），耳朵/下巴被圆裁掉 | 浮岛小头像里**耳朵缺一块**，看着别扭 |
| **③ 只有「头」没有「身」** | 13 张都是大头特写，`manifest.json` 里规划的 `fox-only/` 目录**实际不存在** | 空状态只能放大头，缺全身/半身姿态，页面显得单调 |

其中 ① 最要命——它是「不和谐」的主因。

## 1. P0 必做：13 张表情抠成透明底（性价比最高）

**做法**：把现有 13 张的狐狸主体扣出来，背景去掉，输出透明 PNG。

| 项 | 规格 |
|---|---|
| 尺寸 | 512×512（保持），主体居中留 ~8% 安全边距 |
| 格式 | **PNG-32 透明底**（现在是 `mode=P` 调色板，要转 RGBA） |
| 数量 | 13 张（12 档 + 1 张 default） |
| 命名 | `fox-only/icon-{state}-d{NN}-fox.png`（沿用 manifest 已规划的名字） |
| 体积预期 | 每张 ≈25–35KB（透明底比实色底更小），总计 **≈400KB** |

**为什么这是第一优先**：改完把 `FoxAvatar` 的 `<img>` 换成新图，**整个 App 的狐狸立刻统一**。背景色完全交给 CSS 控制，跟页面主题走。这一步做完，和谐度提升 70%。

**我可以代劳**：这是纯图片处理（去背景 + 裁安全边距），我用内置的图像处理能力直接生成，不需要你动手。你只需要确认「狐狸本体的边缘可以接受算法抠图」。

## 2. P1 强烈建议：补 8 张姿态/物件（场景层次感）

现在 App 里的狐狸只有「脸」，缺「身体语言」。以下 8 张能让空状态和庆祝场景活起来：

| 需求 | 用途 | 提示词要点 |
|---|---|---|
| **全身站姿·开心** | 空状态、引导页 | 直立、挥手、蓝领巾、太阳徽章 |
| **全身站姿·失落** | 缺勤空状态 | 低头、尾巴垂地 |
| **半身·伏案学习** | 学业中心空态 | 桌前、书本、眼镜反光 |
| **半身·看手机** | 待办/通知空态 | 握手机、疑惑表情 |
| **抱救生圈游泳** | 服务页/集市空态 | 救生圈、海面、只露上半身 |
| **举牌子（可留白）** | 通用空状态 | 空白木牌，文字由 CSS 叠加 |
| **睡觉打呼** | 深夜/无数据 | 蜷成一团、Zzz |
| **敬礼 / 比赞** | 完成态、成功态 | 单爪敬礼 |

**规格统一**（重要，否则又会出现「不和谐」）：

```
透明底 PNG · 长边 1024px（够 2x 屏）
主体居中 · 四周留 10% 空白
光源方向：左上 45°（与现有 13 张保持一致）
色板锁定：
  主体橙 #F5A623 / #FF8A3D
  眼镜框 #2F1F14（深棕黑）
  领巾蓝 #2B7FFF
  徽章金 #FFD44A
  画面里不要出现「背景」——天空/海面/夜景全部去掉
```

**提示词模板**（可直接给设计师或生图工具）：

> 一只橙黄色卡通小狐狸，戴黑色圆框眼镜，脖子系蓝色领巾，胸前有金色太阳徽章，日系厚涂插画风格，柔和高光，左上 45° 光源。**透明背景，不含任何场景元素。** 主体居中，四周留白 10%。长边 1024px。

把「动作」换成上表里的姿态即可。**同一批出图**，才能保证 8 张风格一致。

## 3. P1 建议：海洋背景图 2 张（呼应你之前的「海洋狐狸风」）

你之前提过深蓝海洋渐变风，但现在的狐狸背景是白天蓝海 + 紫夜 + 火海。建议补两张**纯净背景层**（无角色），由 CSS 叠在狐狸后面：

| 需求 | 用途 | 要点 |
|---|---|---|
| **深蓝海洋渐变（空状态底）** | 全站空状态统一底 | 上 `#0B2A4A` → 下 `#1E5A8A`，极简水波，无杂物 |
| **浅蓝天海渐变（首页/服务页底）** | 页面顶部光晕 | 上 `#E8F4FF` → 下 `#FFF8F0`（**与现有 `--page-top/--page-mid/--page-bot` 对齐**） |

**为什么值得做**：空状态目前是「白卡片 + 大头狐狸」，加上渐变底 + 光晕后，会立刻有「狐狸在海边等你」的氛围，跟番茄钟的沉浸页呼应。

> 也可以**不做图、纯 CSS 实现**（`radial-gradient` + `linear-gradient`），零体积。我倾向先 CSS，看效果再决定要不要出图。

## 5. P2 可选：桌面图标那 13 张（现状可用，不用改）

`icons/icon-*.png`（带背景那 13 张）**继续给 Android 桌面图标用**——那里需要满幅实色底，**反而不能是透明的**。所以：

- 13 张**带背景**版 → 保留，专供桌面 `activity-alias`
- 13 张**透明**版（P0 新产出）→ App 内所有狐狸位

两套并存，各司其职。**你不需要重做这部分。**

## 9. 验收标准（避免又出现不和谐）

- [ ] 13 张透明版放进任意底色（白/浅蓝/深蓝/绿）都不出现「方块底」
- [ ] 圆裁后耳朵、下巴完整，不被切
- [ ] 13 张并排看，光源方向、色温一致（**同一批出图**是关键）
- [ ] 与 `--green` / `--blue` / `--sun` 三色共存不冲突
- [ ] 单张 ≤35KB，13 张总计 ≤450KB
- [ ] 暗色主题下边缘不发灰（透明底 PNG 不会，但要注意描边颜色）

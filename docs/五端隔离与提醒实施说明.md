# 五端隔离与业务提醒 — 已落地说明

## 代码

| 模块 | 作用 |
|------|------|
| `src/lib/shell-guard.ts` | 路由白名单，工作壳禁入学生页 |
| `src/components/ShellRouteGuard.tsx` | 误入重定向 |
| `src/lib/shell-notify.ts` + `ShellNotifyHost` | 各端轮询提醒 + 本地通知 |
| `src/lib/reports.ts` + `AdminReportsPage` | 举报提交 / 管理处理 |
| Settings / RemindHost | 课表提醒仅学生端；工作端显示「工作提醒」说明 |

## 各端提醒

- **档口/商家**：未读 `order_new` / `shop_order_new` → 横幅 + 系统通知
- **骑手**：待接单池变多 →「有单可抢」；新配送单 →「系统已派单」
- **管理**：待审角色 / 合伙人 / 举报 / 提现 → 横幅；`/admin/reports` 处理举报
- **学生**：原 `RemindHost` 课表/考试/考证；广场举报写入 `reports`

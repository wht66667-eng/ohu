## 2. Windows 准备

1. 从 [Sideloadly 官网](https://sideloadly.io/) 下载适合电脑的 Windows 版本并安装。
2. 按官网当前要求准备其链接中的 **网页版 iTunes、iCloud**。官网说明 Microsoft Store 版需要先替换；已安装时先核对版本来源，不必重复安装。
3. 用能传输数据的 USB 线连接 iPhone，解锁手机，点“信任这台电脑”并输入手机锁屏密码。先确认 iTunes 能识别该手机。
4. 准备自己的 Apple ID、密码和双重认证设备。**全部由你在本机工具与 Apple 验证界面自行输入，不发到聊天、MD 或 GitHub。**

驱动和安装要求见 [Sideloadly 官方首页](https://sideloadly.io/)，连接失败处理见 [官方 FAQ](https://sideloadly.io/faq)。

## 3. 本人签名并安装

1. 打开 Sideloadly，在设备列表中选中自己的 iPhone。
2. 将学生端 `*-unsigned.ipa` 拖入窗口，填写用于个人测试的 Apple ID。
3. 使用普通安装方式，暂不修改高级选项、注入插件或自行更改 Bundle ID。点 **Start**，按工具提示完成登录与双重认证。
4. 等待签名、传输及安装结束，确认工具显示成功且手机出现“哦狐”图标。
5. 记录此次使用的 Apple ID 和工具最终使用的 Bundle ID。以后续签或覆盖更新保持相同，避免被安装成另一个应用；密码不用记入本文。

工具可能为免费账号调整标识以满足 Apple 限制，应以实际安装结果为准。不要为反复试错不断更换标识。安装管理端时使用管理端 IPA，不覆盖学生端。覆盖更新建议先确认账号云同步和重要本地数据，避免先卸载旧应用。[Sideloadly 安装、覆盖与标识说明](https://sideloadly.io/faq)

## 4. iPhone 首次打开

1. 如果提示“未受信任的开发者”，进入“设置 → 通用 → VPN 与设备管理”，找到此次 Apple ID 对应的开发者项并信任。菜单名称随系统可能略有区别。[Sideloadly 官方 FAQ](https://sideloadly.io/faq)
2. iOS 16 及以后如提示需要开发者模式：进入“设置 → 隐私与安全性 → 开发者模式”，开启后按提示重启；重启解锁后再次确认“开启”并输入锁屏密码。
3. 若暂未出现开发者模式选项，先完成上面的连接、配对和首次安装，再按设备及工具提示处理；不要因此购买共享证书。Apple 说明该选项和开发配对状态有关。[Apple 开发者模式说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)
4. 打开哦狐，按实际使用需要授予通知权限。安装成功和提醒验收是两件事，见下节。

## 5. 首次真机验收

- 登录自己的应用账号，检查学生端主要页面；管理端使用有权限的管理账号。
- 在“设置 → 通知 → 哦狐”中检查允许通知、锁定屏幕、横幅和声音。确认音量、静音开关与专注模式的实际状态。
- 先用自检提醒确认基本送达，再用真实待办或真实课程分别测试：前台、返回桌面、锁屏、划掉最近任务后锁屏。记录实际到达时间以及声音、触感表现。
- iOS 当前使用系统通知声音，震动/触感受系统设置控制；不能直接照搬安卓的后台守护、精确闹钟和独立震动开关。应用运行时会过滤超过 30 分钟的过时课程；应用关闭后，已提交给 iOS 的通知无法再由网页代码在展示前拦截，不能承诺系统延迟通知也有相同的 30 分钟丢弃效果。
- 本轮未接入 APNs 云推送，安卓的 APK 更新和安卓热更新不适用于此 iOS 包。当前 iOS 热更新关闭。
- 此个人测试包未填 Apple Team ID，因此未启用依赖该标识的 freeRASP 运行时防护。将来制作正式签名版前，还需核对该插件的 SPM 注册适配；不能把本次编译成功视为该防护已验证。

**云端编译和包结构校验不等于已经完成 iPhone 验收。** 若发现问题，记录机型、iOS 版本、操作步骤及提示原文即可，不需要提供账号密码。

## 6. 7 天到期前续签

免费账号签名通常有效 7 天；到期后需重新签名。使用相同 Apple ID 和相同实际 Bundle ID，在 Sideloadly 中再次安装同一 IPA，覆盖原应用即可，不要先卸载。免费账号在较新 iOS 上通常同时最多安装 3 个自签应用，且存在每 7 天最多创建 10 个 App ID 的限制，已有其他自签工具也可能占用额度。[Sideloadly 账号限制与续签说明](https://sideloadly.io/faq)

先掌握 USB 手动续签，再考虑自动续签。自动续签需要电脑上的 Sideloadly 后台程序运行，并能通过 USB 或已配置的同网 Wi-Fi 连接发现手机；手机离线或电脑关机时不能保证续签。[Sideloadly 自动续签说明](https://sideloadly.io/faq)

| 情况 | 处理 |

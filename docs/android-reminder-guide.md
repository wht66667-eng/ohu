# 哦狐安卓提醒使用说明

进入 **我的 → 设置 → 通知与提醒**。先登录自己的账号、同步本学期课表，再开启上课提醒并核对页面的安排结果。没有课程、权限未允许或安排失败时，按页面提示处理；开关亮起本身不代表已经安排成功。

这份说明对应当前工程里的安卓提醒功能。手机品牌、系统版本、通知设置和省电限制会影响实际到达，请完成文末的实机自检。网页版关闭后无法持续按时提醒。

## 自己选择提醒时点

也可从 **课表右上角「提醒」** 或 **考试页的提醒设置** 进入。

- **上课提醒**：课前和开课时可分别开启。课前可填写 5～60 的整数分钟，也可选常用时间；填写后点 **保存提前时间**。开关调整后立即保存并更新计划，关闭总开关会停止课程提醒。
- **考试提醒**：分别选择前一天提醒时间、提前多少小时以及开考时是否提醒。提前时长支持 0.25～24 小时，需对应整数分钟；例如 0.5 小时为 30 分钟。所有调整点 **保存考试提醒** 后一起生效。

关闭单个时点会保留它上次有效的时间，全部时点关闭后不安排该类提醒。考试只有日期、时间待定或时间无效时，不会猜测一个开考时刻发送通知；请先同步并核对考试安排。

页面会分别说明设置是否保存、提醒计划是否更新。出现“设置已保存，但提醒未能更新”时，按提示处理权限或重试；不要把已保存当作已经成功安排。重新授权或同步课表会保留你主动关闭的上课提醒。

## 选择 App 内的显示方式

| 显示方式 | 使用体验 |
| --- | --- |
| 顶部横幅 | 默认轻量提示，继续当前操作；点横幅展开详情 |
| 底部卡片 | 展示完整安排，可查看课表或确认关闭 |
| 居中弹窗 | 更突出当前提醒，适合希望明确确认的场景 |

多条提醒依次展示，其他提醒保留在列表中。关闭一条只处理这一条；关闭课表提醒会撤销课表计划并移除等待展示的课程卡片。

“预览当前弹窗”只展示界面样例，没有安排系统通知，也不会播放声音或震动。App 内弹窗主要用于正在使用哦狐时；锁屏与后台请观察系统通知。

## 选择普通、安静或重要提醒

| 样式 | 默认取向 |
| --- | --- |
| 普通提醒 | 标准通知，适合日常上课提醒 |
| 安静提醒 | 较少打扰，默认无声音和震动 |
| 重要提醒 | 更高优先级，适合需要突出提示的安排 |

三种样式分别使用自己的系统通知类别。更换样式后，后续重排会使用新类别，需要重新核对它的声音、震动与锁屏显示。系统可能把“通知类别”称为“通知渠道”。用户对已存在类别的修改会保留，哦狐不会强行重置。实际横幅、声音和震动由系统与类别设置决定。[Android 通知类别说明](https://developer.android.com/develop/ui/compose/notifications/channels)

## 设置声音、音乐和震动

1. 先在 App 里选好提醒样式。
2. 点 **选择铃声、音乐与震动**，进入该类别的系统设置。
3. 检查通知已允许，按需要选择声音、震动、横幅与锁屏显示。
4. 返回 App，安排一次自检，观察手机的实际表现。

能否选择本地音乐取决于手机的系统声音页面。静音、勿扰、专注模式和音量仍由手机控制；“重要提醒”不会自动绕过它们。

如果以前的提醒没有声音，先检查原有类别；也可以明确重新选择一种样式，再检查新类别。安静提醒已经在系统里被自己修改过时，也应以该类别的当前设置为准。

## 开机恢复与手机厂商后台设置

**开机恢复提醒**用于重启后恢复本账号已保存、尚未到时的提醒。关闭它不会立即撤销当前已安排的提醒；重启后需要重新打开 App 安排。开启恢复不会自动打开首页或弹出授权页面，已过期提醒不会在开机后补响。

先允许通知，并按页面提示允许 **闹钟和提醒 / 精确闹钟**。未允许精确闹钟时，系统可能推迟提醒。[Android 闹钟说明](https://developer.android.com/develop/background-work/services/alarms)

点 **允许手机厂商自启动**，按手机提供的页面检查自启动、应用启动管理、后台运行或电池限制。设置名称随手机变化；如果快捷入口没有打开，可在系统设置里搜索这些名称，再找到哦狐。只调整实际需要的选项，并用自检确认结果。

从最近任务中划掉 App 与系统设置里的 **强行停止** 不同。强行停止会暂停提醒；Android 15 还会取消待触发的计划，需要重新打开 App 后恢复。手机关机期间无法响铃。[Android 强行停止说明](https://developer.android.com/about/versions/15/behavior-changes-all#enhanced_stop_states)

## 桌面覆盖小卡片

桌面覆盖默认关闭。需要时，先点 **打开系统授权**，允许哦狐显示在其他应用上层；返回后再手动开启 **桌面覆盖**。

它只在亮屏且已解锁时显示，能手动关闭，约 12 秒后自动收起。锁屏或熄屏时请查看系统通知。覆盖卡片共用课程计划，不另外播放铃声或震动；点“查看课表”可以进入对应入口。

“预览桌面覆盖”只检查样例是否显示，没有发送后台通知。已开启但显示 0 条时，目前没有可触发的课程；检查有效课表、课表开关与安排结果。切换账号或明确退出会清理原账号的覆盖计划。

## 在自己的手机上逐项自检

先检查通知、当前类别和精确闹钟设置。每次重新安排一条测试，再单独验证一个场景；同一条测试会被下一次测试替换。

| 场景 | 操作 | 记录 |
| --- | --- | --- |
| App 打开 | 点“自检提醒”，等约 1 分钟 | 实际到达时间、系统通知、声音与震动 |
| 锁屏 | 再安排一次，锁屏等待 | 是否显示锁屏通知、是否按需要响铃 |
| 后台 | 再安排一次，回桌面或打开其他 App | 系统通知是否到达 |
| 最近任务划掉 | 再安排一次，从最近任务划掉哦狐 | 通知到达时间；不要用“强行停止”替代本场景 |
| 重启 | 登录当前账号、开启开机恢复，点“安排 3 分钟后的重启自检”；确认安排成功后，在到点前重启并解锁 | 该测试是否恢复、到达时间；不要用普通 1 分钟自检代替 |
| 关闭提醒 | 关闭上课提醒后观察原计划到时 | 原课程提醒是否撤销；若页面报清理失败，处理后重新验证 |

普通 1 分钟自检用于当前手机的通知显示、锁屏与后台检查，不恢复到重启之后。3 分钟重启自检绑定当前登录账号，需要开启开机恢复并通过通知权限检查；它只验证这一台手机的恢复流程。重启耗时超过测试时间时，过期测试不会补发，请重新安排一次。

桌面覆盖不由这两种系统自检触发：请用“预览桌面覆盖”检查显示，再用一条未来真实课程观察实际卡片。每次记录手机型号、系统版本、App 版本、计划时间与到达时间。一次成功只说明该场景通过，不能代替其他场景。

若自检失败，依次查看页面安排结果、App 通知总开关、当前类别、精确闹钟、勿扰与厂商后台设置。重新打开哦狐后检查并刷新提醒。把失败场景和到达时间反馈给维护者，比只说“没提醒”更容易定位。

## 课表更新和持续提醒范围

提醒基于当前账号已经同步并保存在手机上的课表。学校调课、更换学期、课程或上课地点变化后，请重新同步，核对新计划；自启动和开机恢复不会自动获得新的云端课表。

支持后台补排的新安卓版本，会在本账号当前通知安排成功后，保存手机上已有的本学期课程，并每天静默补充未来 7 天的提醒。最多保存从本次刷新日起 210 天内的课程候选；补排不会另发一条提示或重复响铃。通知被关闭、课表关闭或账号退出时会停止相应计划，重新开启后请打开 App 刷新。

确认页面出现“后续本机课表已保存供后台补排”的结果；如果提示补排未保存、安排失败，或当前安装版本仅支持未来 7 天，请按提示处理或更新安卓 App。开机恢复关闭时，重启后的补排会暂停，重新打开 App 才重新安排。

后台补排只能使用手机已经保存的本学期内容。计划结束、课表过期或学校变更时仍需重新同步；它不会自动下载新云端课表，也不能保证绕过强行停止、关机或手机后台限制。

目前代码与隔离检查已核对，通知实际送达、长期后台补排、重启、声音震动和手机厂商限制仍需按上表实机确认。

## 正式整理前的核验清单

1. 确认软件名称、登记版本号、开发完成日期、是否发表和首次发表日期；不要从文件修改时间推定完成或发表日期。
2. 对照 Git 提交、发布记录、APK 与 OTA 的版本来源，选定对应的完整代码基线；如果正式版本来自其他分支或工作树，以真实记录为准。
3. 确认著作权归属、共同开发或职务开发关系，检查第三方代码、素材及许可；必要时准备权属证明。
4. 从同一代码基线按实际代码顺序排版源码鉴别材料，核对官方要求及例外情形，不能虚构代码或调整内容冒充其他版本。确认申请材料、截图与源码的名称、版本一致。
5. 安全复核后再对外提交，排除凭据、个人信息及与申请无关的敏感数据；如需特殊交存，按登记机构要求办理。

## 二、可供核验的软件技术信息

- 软件用途：面向校园用户，提供课程安排、任务、校园服务、广场和专注计时等功能入口。具体功能应以申请版本为准。
- 开发语言和技术：当前工作区以 TypeScript、React、CSS 为主，包含 Capacitor Android 工程及云端相关代码；最终按实际选取的申请版本填写。
- 开发和运行环境：开发硬件、操作系统、开发工具及实际运行设备型号【待申请人根据真实环境填写】。当前 Android 工程配置最低 API 23，并不能代替设备兼容性验收。
- 软件规模（源程序量）：【按最终选定申请版本实际统计】。切勿把本工作快照所选文件的行数直接当作整个软件总代码量。
- 软件主要功能与技术特点：围绕真实实现和所选版本填写，外部教务、校园卡等服务是否支持，以接入范围及实际运行情况为准。

## 三、材料准备和复核

1. 确定申请版本，保留可核验的 Git 提交、发布包及热更新对应关系；存在工作区未提交变更时另行固定并核对。
2. 核对独立开发、合作、委托、职务开发等实际情况，以及所使用第三方代码、图片和字体的授权；按申请情形准备身份证明与其他权属证明。
3. 选取对应版本的真实源程序与真实使用说明书。通常源程序和文档分别提交前、后各连续 30 页；不足 60 页的提交全部。每页行数、页码、例外方式及电子提交要求以登记机构现行规定和具体申请方式为准。
4. 按真实界面补充已登录状态和主要操作流程截图；当前说明书截图只显示本地隔离环境的未登录状态。
5. 按登记系统的要求填写并提交申请。本目录仅供整理和本地审核，尚未填写官方申请表，也未提交申请。

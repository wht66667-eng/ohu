# 修改与优化建议（下一迭代）

按投入产出排序，可直接排期。

## P0 · 体验与安全

1. **教务密码勿存明文/弱 XOR**  
   本机记住密码改成系统 Keystore / iOS Keychain，或只记学号、每次手输密码。
2. **签名密码走环境变量**  
   `android/app/build.gradle` 默认 `sunshine123456` 仅限本地；CI/发包必须用 `SUNSHINE_STORE_PASSWORD`。
3. **Web 资产仍可抽**  
   R8 只保护 Java 层。长期：敏感逻辑放云函数；前端可对 `dist-app` 做混淆（如 javascript-obfuscator）或拆 chunk + 短 TTL 远程配置。
4. **商业加固（可选）**  
   若上架后被脱壳抄袭，再考虑腾讯乐固 / 360 加固；注意与 Capacitor 兼容性，需实机回归课表与通知。

## P1 · 学业与提醒

1. 考证提醒支持「报名截止 / 查分日」多节点，而不是单日期。  
2. 上课提醒设置页增加「震动 / 语音」独立开关（有人在图书馆不想出声）。  
3. 考试提醒与考证提醒合并到「提醒中心」列表，可一次性清除。  
4. 准考证号字段（本机加密存储），查分一键粘贴。

## P2 · 管理后台

1. 启用 `admin_accounts.perms` 细粒度（内容 / 财务 / 成员），避免所有管理员权限过大。  
2. 成员治理页补「封禁 / 解封」UI（RPC 已有）。  
3. 操作审计表：谁加了管理员、谁下架了内容。

## P3 · 性能与壳

1. 课表 Three.js / 大图懒加载已有基础，继续对首页轮询接口做可见时刷新。  
2. APK 分 ABI + App Bundle 上架，减小下载体积。  
3. 冷启动：预热 `/api/health`，减少首次同步超时。

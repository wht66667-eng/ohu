# 哦狐多校课表接入计划与问题记录

记录日期：2026-10-20  
项目：哦狐／阳光校园  
当前状态：海大保留原有同步，其他四校尚未接通个人课表同步。  
本次操作：只保存本文，不继续修改功能，不打包、不上传、不提交热更新。

## 1. 最终要实现什么

用户需要的不是相同样式的外部链接，而是以下完整流程：

1. 在哦狐“课表”页面选择学校。
2. 浏览学校和查询说明不需要登录；开始绑定、同步等功能时，先完成哦狐手机号登录。
3. 在哦狐内输入本校学号、教务密码，按学校要求完成验证码或额外认证。
4. 同步成功后，在哦狐内显示本人的课程、周次、星期、节次、教师与教室。
5. 保存属于当前哦狐账号和学校的课表，重启后仍能查看；根据本校作息和用户设置安排提醒。

江苏海洋大学现有教务查询方式保持不变。其他学校的操作尽量与海大一致，但必须使用各校自己的认证和课表接口。

其中“使用功能先登录哦狐”的要求尚需单独检查并补齐，不能把它写成已完成的功能。

## 2. 这次查明的问题

- 之前新增的四校功能只有学校官方网页入口和查询说明，没有实现哦狐内的个人账号登录与课表同步。
- 现有课表后台固定访问江苏海洋大学，不是通用教务接口；不能只复制海大的表单或更换学校名称。
- 各校认证方式、校园网络限制、课表数据结构不同，必须分别适配。
- 当前课程缓存有哦狐账号归属，但学校、学期、作息和提醒的隔离还不完整，直接接入可能覆盖另一学校的数据或排错提醒时间。
- 用户目前没有其他四校的测试账号，尚未验证任何新学校的登录成功、个人课表读取及显示结果。

因此，目前不能把任何新学校标记为“已支持哦狐内同步”。

## 4. 本地已经做了什么

- 课表顶部提供五校选择，并记住本机选择。
- 海大继续使用原有绑定和同步界面。
- 其他四校明确显示“本校课表同步尚未接通”。
- 学校官方入口保留在“临时查询：学校官方入口”中，不把网页跳转称为绑定或同步。
- 不显示会把其他学校账号密码提交给海大的表单。
- 切换查看未接入学校的说明，不代表切换当前提醒绑定，也不应清除已有海大课表或提醒。

这些是本地源码和页面状态的修正，不等于新学校已经接通。

## 5. 后续实施顺序

### 第一步：取得一所学校的验证条件

优先接入能取得正式资料和验证条件的学校，逐校完成，不同时把四校标记为支持。

可用条件包括：

- 学校提供正式接口规范及可用的授权测试环境；或
- 本校学生在自己的设备上自行登录，并配合核对结果、提供去除个人信息的页面或课表结构样本。

不要把密码、完整 Cookie、登录票据或验证码提交到聊天记录和项目样本中。只有课表导出文件时，可以帮助验证解析与显示，仍不能证明账号登录流程可用。

### 第二步：完成各校认证和课表解析

- 为每所学校建立独立适配器，由后台固定登记支持的学校与能力。
- 登录会话明确绑定学校，不能跨学校使用，也不能让客户端任意指定上游地址。
- 按实际情况处理验证码、会话过期、错误密码、网络不可达与二次验证。
- 读取学校真实返回的学期和个人课表，不能把登录页打开当作同步成功。
- 学校不支持或尚未适配成绩、考试时，不能用空数据覆盖已有资料。

### 第三步：补齐学校和账号隔离

课程、成绩、考试、作息、校历和凭据应区分：哦狐账号、学校、绑定学号及学期。

- 旧数据仅按海大兼容读取，不自动归给新学校。
- 用户切换账号或学校后，旧请求的晚到结果不能写入当前页面、缓存或提醒。
- 学期起点、节次数量、单双周和调课规则按本校实际资料处理，不能统一套用海大。
- 只有明确切换生效的课表绑定时，才更新相应提醒；浏览学校列表不改变提醒计划。

### 第四步：完成统一使用流程

- 未登录者可以浏览；绑定与同步需要先完成哦狐登录，再进行学校教务认证。
- 同步过程有进度、错误原因和重试入口。
- 明确区分“未绑定”“暂未接入”“学校连接失败”“同步失败”“当前无课”等状态。
- 同步成功后直接显示哦狐课表，而不是跳往另一个网页结束流程。

### 第五步：完成真实验收后再决定发布

逐项满足下一节验收条件，再准备新的更新包。本文件不构成发布授权。

## 6. 每所新学校的验收清单

- [ ] 从实际运行环境能访问学校认证和教务服务。
- [ ] 正确账号可以完成认证；错误密码、验证码错误和会话过期有清楚反馈。
- [ ] 需要二次验证时能按学校要求完成，不绕过认证。
- [ ] 哦狐内的课程与学校原课表逐项一致。
- [ ] 学期、周次、单双周、星期、节次、教室和教师解析正确。
- [ ] 无课、跨学期、重复同步和解析失败不会错误清空已有课表。
- [ ] 退出、切换账号及切换学校后，不出现串账号或旧请求覆盖。
- [ ] 重启或离线查看使用的是当前账号所属学校的正确缓存。
- [ ] 提醒采用本校实际作息，按用户选择的通知、声音、震动分别生效。
- [ ] 实机验证划掉最近任务、锁屏到点后的课程提醒，不能仅用自检代替。
- [ ] 海大原绑定、同步、缓存和提醒功能没有回归问题。

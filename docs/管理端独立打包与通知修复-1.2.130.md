# 管理端独立打包与通知修复（1.2.130）

管理 APK 与管理 OTA 使用独立的 `main-admin.tsx → AdminApp.tsx` 入口；学生 APK 保留原入口，电脑 H5 仍支持管理后台和学生预览。发布标记分别为 `admin`、`student`、`shared-web`。Vite 在构建管理端时拒绝引入学生首页、课程页面、朋友圈、发布面板、个人提醒宿主和课程排程模块。

管理端保留内容治理、公告、举报、成员权限、管理消息、工作会话和账号设置；管理通知只展示现有后端的 `report_new`，不将个人待办、积分与其他学生通知混入工作中心。“全部已读”只标记显示的工作通知 ID。管理通知使用独立渠道“哦狐管理工作通知”，按系统铃声、震动与锁屏设置工作。当前新举报通过在线轮询同步，关闭应用后的云端推送未接入。

每条工作通知带账号和会话归属；同一进程 A→B→A 的旧点击失效，冷启动同账号恢复后仍可处理合法点击。切换或退出账号只撤销管理通知。调度成功后才写入去重标记；权限拒绝或系统调度失败会保留重试机会。Android 8.0 前不支持通知渠道的明确返回会降级到普通通知，真实渠道错误继续显示。

覆盖升级旧管理 APK 时，原生迁移在应用创建、恢复和旧提醒恢复入口撤销学生个人系统闹钟、补排、桌面覆盖提醒与守护；保留管理通知、其他业务通知、账号、课表缓存和云端数据。旧闹钟广播的个人提醒拦截与本地通知恢复过滤由同一 `StudentReminderPolicy` 分类。完整原生保护需安装 1.2.130 APK。

验证：类型检查通过；14 个管理打包/通知/原生定向测试通过；33 个浏览器隔离场景通过，覆盖独立管理入口与共享 H5 的消息、通知、设置、失败状态、已读范围、390/1024 宽度和浅深色。原生迁移行为测试包含遗留闹钟、已送达通知、admin-work 编号碰撞、重复清理、系统恢复和学生壳保留。已查看实际截图并修正深色工作提醒横幅对比度。未连接真机，不将 JVM/浏览器结果视为锁屏送达或实际铃声验收。

检查记录：`.codex/qa/admin130-final.json`、`.codex/qa/admin130-ui.json`；浏览器脚本为 `.codex/admin130-ui-qa.cjs`（独立端口 43124）。最终 APK、OTA 与 H5 的上线及线上字节核验由本轮主流程执行。

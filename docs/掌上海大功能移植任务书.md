## 二、需要新增：PU 口袋校园

### 2.1 入口

```
https://class.pocketuni.net/r
```

### 2.2 数据接口（已抓包实测）

```
GET https://apis.pocketuni.net/apis/credit/index?puType=0&year=0
    → {"data":{"totalCredit":4.85,"activityCredit":4.25,"applyCredit":0.6,
               "pai":{"rank":0,"over":0,"level":""}}}

GET https://apis.pocketuni.net/apis/credit/activity?puType=0&year=0
    → {"data":{"credit":4.25,"list":[{"name":"【素质拓展A类】…","credit":0,"ids":[…]}]}}

GET https://apis.pocketuni.net/apis/credit/apply?puType=0&year=0
    → {"data":{"credit":0.6,"list":[…]}}

GET https://apis.pocketuni.net/apis/credit/activityList
    → {"data":{"pageInfo":{"count":36,"total":4,"page":1,"limit":10},"list":[…]}}
```

鉴权：`Authorization: Bearer <token>`

### 2.3 已知难点（Flutter 版踩过的坑）

1. **token 不在 localStorage**：`localStorage.oauth_token` 与请求头里的 Bearer 值**不同**，直接拿来用会 401 Please Login。真 token 在 Vuex 内存里。
   → 可行解法：注入 `fetch` / `XHR` 钩子截获 App 自己请求头里的 Authorization，再复用。
2. **成绩明细页是纯文字，成绩单页是 canvas**：
   - `class.pocketuni.net/r#/score/detail` ← 文字里有全量分类学分，可正则解析
   - `class.pocketuni.net/r#/score/myscore` ← canvas 渲染，读不到文字，需 OCR
3. **页面是 Vue + Element UI + Tailwind**，class 全是工具类（`flex`、`text-[14px]`），**不要按固定 class 抓 DOM**，按文字正则。

### 2.4 建议实现方式

优先走 **WebView + 页内 fetch**（和现有 Chaoxing/Physical 面板同构）：

```
新建 src/lib/pocketuni.ts
新建 src/components/PocketUniSyncPanel.tsx
新建 src/pages/study/PocketUniBridgePage.tsx（如需 WebView）
```

## 三、可复用：WebVPN 编码算法

哦狐如果要在 App 内直接访问校内系统（不走 WebView），需要这个：

```
入口  http://webvpn.jou.edu.cn:58888
路径  /{scheme}[-{port}]/{hex(host)}/path
hex   = hex(IV) + hex(AES-128-CFB(key=IV="wrdvpnisthebest!", pad16(host)))
```

**必须用 http**：`https://yx.jou.edu.cn` 会被 WebVPN 判为连不通。

Flutter 版有可直接翻译的参考实现：`flutter_app/../tools/wrdvpn_encode.py`。

## 四、可新增：智慧学工（综测/文化成绩）

```
入口      http://yx.jou.edu.cn/          ← 必须 http
应用清单  /api/zhxg-fwgl/appManagement/getAllAppInfo
学生信息  /xsxx/
分类清单  /xsxx/api/sm-dynamic-form/openapi/getXszhxxglb
分类数据  /xsxx/api/sm-dynamic-form/dynamicShow/queryBdzdInfoOneMany?id=<flid>&csrfToken=<t>
```

`csrfToken` **每次请求动态签发**，不在 cookie 里 → 只能在页面上下文里 fetch。

CAS 已注册该校服务（实测票据可签发），走 SSO 可直进，不需要额外账号。

## 六、硬约束

1. **不要把密码、token、cookie 写进仓库**
2. 改代码用文件级编辑，不用 PowerShell 内联字符串替换（曾多次静默失败）
3. 改完自行验证构建（`npm run build` 或 `pnpm build`），别只看代码
4. 校园密码不要反复试，遇 `INVALID_ACCOUNT` 立即停
5. 学校拒绝腾讯云出口 IP，**云端无法直接登录学校系统**，取数必须在设备侧

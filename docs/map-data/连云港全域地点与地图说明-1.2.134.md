# 连云港全域地图与地点数据（1.2.134）

此版本把现有 MapLibre 校园地图扩为连云港全域入口，提供“全部 / 美食 / 好玩”筛选、地点详情和登录后打卡。学生可添加本机地点，先保存在当前设备；登录后也可提交云端审核，管理员通过后自动保留到共享地图。打卡默认仅自己可见；用户主动申请公开后进入管理端审核，批准后才公开。

## 底图与范围

- 默认底图采用 [OpenFreeMap Liberty](https://openfreemap.org/quick_start/) 的 MapLibre 样式；它展示 OpenMapTiles 与 OpenStreetMap 数据。地图上保留底图署名。
- 初始视野用 `[[118.25, 33.95], [119.8, 35.12]]` 近似覆盖连云港市域；管理员仍可缩放查看地点。这是地图初始化视野，不作为行政边界数据使用。
- 学校原有自定义样式继续优先；只有未设置样式时才使用公共默认底图。

## 地点和核验

迁移脚本会添加 13 个公开地图候选地点，包含花果山、孔望山、桃花涧、西双湖、民主路老街、博物馆，以及分布于海州、连云、赣榆、东海的农贸/海鲜市场。坐标来自相应 OpenStreetMap 要素，保存为 WGS84 经度、纬度；数据按 ODbL 1.0 标注来源。候选点可以在地图上浏览，但详情会明确提示“候选位置”，不能据此保证入口、营业时间或现场可达性。

连云港市政府发布的 [A级旅游景区名录（2026年2月）](https://www.lyg.gov.cn/zglygzfmhwz/gcly/content/8144bde5-e008-4c92-a549-8c64a167b4af.htm) 和 [港城美食页面](https://www.lyg.gov.cn/zglygzfmhwz/gcms/gcms.html) 用于确认景点与美食街区的公开名称；夜市和商户状态可能变化。上线前建议管理员逐个核对位置、名称和当前营业状态，再通过管理端添加或修正已核验标点。管理端新增点会写入“已核验”标记。

## 数据库迁移

按顺序执行：

1. 若环境从未建过地图/校园圈表，先审核并应用 `docs/sql/campus-map-132.sql`。
2. 再审核并应用 `docs/sql/campus-map-city-134.sql`。

第二个脚本可重复运行：新增地点来源/核验字段、全域入口、候选地点、`campus_poi_checkins` 和学生地点申请表。它不会清理现有账号、校园动态或提醒，也不会自动改写线上数据。应用后到哦狐管理端的“地图地点与校园圈”审核学生地点及公开打卡。

## 费用与服务限制

默认公共底图便于先验收交互；生产流量、可用性和服务条款应按 OpenFreeMap 当前条款评估。若需要自有 SLA、稳定高并发或离线地图，应在 CloudBase Run 自托管矢量瓦片和样式，数据存 COS 持久化挂载；不要把大型瓦片归档进可能重启清空的容器临时目录。

OSM 数据需要署名，参见 [OSM Attribution Guidelines](https://osmfoundation.org/wiki/Attribution_Guidelines)。公开底图样式快速接入方式见 [OpenFreeMap Quick Start](https://openfreemap.org/quick_start/)。

# 哦狐 1.2.130 发布验收

日期：2026-10-21。安装包版本 1.2.130／130，界面版本 1.2.130／130。

学生端 APK、管理端 APK、两端热更新及电脑网页均已上传。发布后重新下载四份线上文件，大小与 SHA-256 全部匹配；APK 更新清单、两端及兼容旧路径的热更新清单、网页发布标记和首页内容均与准备包一致。

## 本次修复

- 管理端：改用独立管理入口和管理页面打包，移除学生课表、快递、朋友圈及个人提醒模块。管理通知使用独立的工作通知渠道，仅展示现有的举报工作通知。覆盖升级会撤销旧管理 APK 遗留的学生提醒闹钟、补排、覆盖提醒与守护，不删除账号、课表缓存或云端业务数据。管理通知目前通过在线轮询同步，应用关闭后的云端推送尚未接入。
- 学生朋友圈：补齐页面及全局发布入口，支持文字、图片、可见范围、详情、评论、图片放大、点赞与本人删除。读取失败显示可重试错误；发布失败保留草稿。登录及同账号新会话会重建页面，迟到请求不会回填到其他会话。生产数据库已应用好友关系双向可见与评论／点赞父动态权限策略；没有删除或重写用户业务数据。
- 上课提醒：新增“系统闹钟准时提醒”，默认开启，在精确闹钟允许时使用系统闹钟排程，减少休眠合并延迟；系统可能显示下次闹钟图标。铃声与震动保持分别选择，服从实际系统渠道、音量和勿扰设置。原定提醒时间超过 30 分钟的课程在通知、恢复补排和 App 内提示路径中丢弃；已取消或被新计划替代的旧广播不再发声或消费新计划。
- 保留 1.2.129 的七个快递平台入口及单号查询。课表仍使用原江苏海洋大学查询；未发布的多校查询草稿未打入本次 APK、热更新或网页。

## 安装与使用

- [学生端 APK](https://jou-d4gq7a3cqf51e6caa-1394316826.tcloudbaseapp.com/downloads/SunshineCampus-User-1.2.130.apk)
- [管理端 APK](https://jou-d4gq7a3cqf51e6caa-1394316826.tcloudbaseapp.com/downloads/SunshineCampus-Admin-1.2.130.apk)
- [电脑管理后台](https://jou-d4gq7a3cqf51e6caa-1394316826.tcloudbaseapp.com/admin/)

本次热更新最低安装包构建号为 130。当前安装 1.2.129 的手机需覆盖安装对应 1.2.130 APK，打开应用后重新检查“设置 → 通知与提醒 → 上课提醒”。新的闹钟机制、过期拦截和管理端原生清理无法只靠热更新获得。

电脑网页使用腾讯云默认测试域名，首次访问会出现平台的访问提示，倒计时结束后点击“确定访问”进入。这是平台默认域名行为，详见 [腾讯云官方说明](https://docs.cloudbase.net/service/alias)。已用 Microsoft Edge 实际导航、确认提示并检查手机／电脑宽度下的管理入口和学生朋友圈登录入口；没有通过改写响应头或替换线上资源来绕过提示。当前环境未绑定自定义网页域名。

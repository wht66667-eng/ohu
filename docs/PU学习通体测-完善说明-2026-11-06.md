## 1. 数据契约（来自真实抓包，不是猜的）

### 1.1 PU 二课

```
GET https://apis.pocketuni.net/apis/credit/index?puType=0&year=0
  data.totalCredit 4.85 / activityCredit 4.25 / applyCredit 0.6
GET …/apis/credit/activity  → data.list[{ name, credit }]
GET …/apis/credit/apply     → data.list[{ name, credit }]
```

页面文字通道（`class.pocketuni.net/r#/score/detail`，文字可选中）：

```
活动类 4.25 + 成果类 0.6 = 总成绩 4.85
【素质拓展B类】团员主题教育（0.85）
【劳动教育】公益劳动（1）
```

分类前缀只有四种：`【素质拓展A类】`、`【素质拓展B类】`、`【素质拓展C类】`、`【劳动教育】`；
`(勿选）`、`已停用` 视为脏数据丢弃。`【素质拓展C类】日常性劳动` 必须判 C 类，不能被「劳动」抢走。

### 1.2 体测（tice.jou.edu.cn:8080）

```
Historyhealth.jsp    序号 | 学号 | 姓名 | 性别 | 学年 | 体测成绩 | 体测等级 | 详细
queryHealthInfo.jsp  项目名称 | 测试成绩 | 分数 | 结论 | 加分 | 减分 | 体测总成绩 | 体测总结论
```

两条硬规则：

1. **0 是有效分数，空才是未公布**（`total` / `score` 都用 `number | null`）；
2. 表格大量用 `rowspan`，首行可能是 `</tr >`（闭合标签带空格），必须按网格展开再按表头定位列，
   否则「学号 `2023120448` 被当成 2023 学年」「第二行起分数列错位」两个 bug 都会复现。

### 1.3 学习通（超星 v8）

课程页文字（第一行课程名，其余行详情）→ 课程清单；不依赖 `getStudyCourse`（实测账号返回空）。

## 3. 口径（写进 UI 的）

1. **PU ≠ 公选**：PU 来自口袋校园独立账号体系，公选来自校园档案；两边不混算、不互相抵扣，成绩页里是两块独立内容。
2. **没读到 ≠ 0**：三个总学分都是可空值，页面显示「—」；只有明细求和能兜底时才计算。
3. **0 分分类不进合计**：明细页大量 0 分项只用于看「还差哪类」，不展示、不累加。
4. **0 分 ≠ 未公布**：体测「0」是有效成绩，「空 / `---`」才是未公布或未计分。
5. **不伪造达标线**：学校未公布 A/B/C 毕业要求，页面只展示已得学分，不写「还差 X」。
6. **只存结构化结果**：不保存账号、密码、cookie、token 或粘贴原文；缓存按哦狐账号隔离（访客独立）。

## 5. 为什么是「粘贴导入」而不是 App 内 WebView

React 套壳（Capacitor 7）当前没有可注入脚本的 WebView 插件，`window.open` 会交给系统浏览器；
而口袋校园 token 只在 Vuex 内存、学习通 `signature` 必须真实跳转、体测是独立账号——
这三条都要求「真实浏览器 + 页内脚本」。Flutter 版有 `webview_auth` 通道，React 版没有。

因此本轮把 **解析、模型、落库、展示、入口** 全部做实，取数用「页面文字 / 接口 JSON 粘贴」，
与既有体测「粘贴文字导入」的产品口径一致。后续要免粘贴，只需补一个 Capacitor WebView 插件，
把页内脚本产出的 `[{title,value}]` 直接喂给同一套解析函数即可，数据层不用再改。

# 学生端按钮与图标：本轮约定

## 已确认的选择

- 学生端优先；管理端单独适配。首页等现有阿狐插画保留。
- 常规按钮轻微按下并回弹；系统启用减少动态效果时关闭通用按压缩放。
- 非狐狸的共用服务图标采用深绿圆润线条。其他页面独立绘制的图标后续逐页核对，避免改变已有业务功能。
- 发布、保存、专注及点赞收藏等关键操作提供轻微触感。当前安卓按系统触觉开关执行；旧版安装包、网页和 iOS 不具备本次新增的安卓触感桥接能力。
- 深色快捷切换位于首页、服务、广场、我的页头；记住手动选择，设置页仍可切回跟随系统。

## 当前实现和限制

通用按压效果覆盖学生端界面内的按钮和链接，既有组件可以保留自身动画；图标先改共用服务图标，狐狸和用户内容图片不替换。关键操作触感按按钮现有名称识别，需要在各真实业务状态下继续逐页核验；原生桥接尚未进行真机验证。信息站发布入口放在标题右侧，保留原来的发布弹窗和账号校验。

## 验收

以 320px 宽的隔离访客环境验证四个主题切换、信息站发布弹窗及首页快捷入口的图片与文字边界。此验证不代表真实设备、所有详情页或全部主题均已验收；需要继续检查深色模式对比度、系统字体放大、键盘交互和手机触感。

# 阿狐 V1 启动与切页验收

平台为 React 19 / Vite / Capacitor 7 WebView；局部沿用暖白、森林绿与狐狸橙。普通页面继续使用原有绿衣阿狐插画。

启动包含 face、achievement、comic 三种布局，使用 V1 透明 PNG。按已确认登录记录加权随机；游客、未恢复或同步未确认时不随机出成就布局。真实记录到达只补文字与图片，不重播。开发预览强制进入成就布局时，未知数字显示「—」。

普通冷启动总时长上限三秒，包含淡出；认证与实际首页准备好可以提前结束。后台恢复没有重启故事的监听。减少动态效果时是静态画面。没有百分比、假登录或预设天数。

主脚本未能挂载时，三秒后转为静态恢复与重试；资源失败保留恢复提示。启动结束不修改认证、路由权限或 OTA ready 判定。

切页未完成满 300ms 才显示已有轻量阿狐 loading，快速页面只淡入 180ms。离开待加载路由会取消延迟提示。

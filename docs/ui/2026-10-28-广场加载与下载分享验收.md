1. 广场动态、热门榜恢复正常纵向滚动。原先整个 `/plaza` 被聊天固定容器的 `overflow:hidden` 裁掉；现在只有 `tab=lobby` 公共聊天保留固定视口。动态与热门榜接入当前栏目刷新。
2. 广场栏目以 URL 为唯一来源，修复浏览器返回、发布链接及发布完成后栏目与外壳布局不一致。
3. 页面切换和内容加载改用独立透明绿衣阿狐，去掉旧像素跑步与尾巴加载图形的混用。新图为 `public/brand/ohu-original/fox-loader-wave-v2.png`，依据用户原素材整理；快速切页不显示加载层，300ms 后才显示，减少动态时停止晃动。保留无狐主题的圆环。
4. 服务底部下载入口进入宣传页，支持三种分享卡配色、保存 PNG、系统分享和复制公开链接。二维码编码真实公开 HTTPS 宣传地址，保留黑白二维码和四模块留白。本地页面说明扫码打开已发布版本。
5. 本地下载页面读取实际已验证学生 APK 的版本、大小和 SHA256；开发服务提供真实 APK 下载。发布准备同时包含宣传页、分享脚本和图片，不覆盖线上更新清单。
6. 修复宣传页手机横向溢出。修复本地预览监听打包目录导致 Windows 文件锁错误退出的问题，构建产物不再触发预览重载。

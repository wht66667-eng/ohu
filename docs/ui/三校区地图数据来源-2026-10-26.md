# 三校区地图地理数据来源与覆盖情况

采集日期：2026-10-26。仅增加本地公开地理资料，没有修改 CloudBase 或发布地图数据。

## 来源与许可

- 几何来源：OpenStreetMap 标准只读 map API，许可 ODbL 1.0，署名 `© OpenStreetMap contributors`。版权页：<https://www.openstreetmap.org/copyright>。
- 校区面检索：Nominatim 的大学名称检索，仅用于找到对应 OSM way；应用几何直接保留 OSM 节点坐标与标签。
- 官方校园示意图入口：<https://international.jou.edu.cn/chinese/lxszssy/hddt.htm>。该页可用于人工核对，但本轮未把官方图片或用户的手绘参考图转换为地理坐标。
- Overpass 端点本轮返回繁忙或超时，未依赖不完整的 Overpass 响应生成文件；改用 OSM map API 的小范围一次性读取。

所有 GeoJSON 使用 WGS84 `[经度, 纬度]`，不使用 GCJ-02 坐标。

## 文件与提取方式

### 苍梧

- 应用数据：`public/maps/jou-cangwu.geojson`。
- 原始数据：`docs/map-data/jou-cangwu-osm-2026-10-26.json`。
- 沿用先前采集的 180 个要素：校园面 1、建筑 104、道路 60、运动场地 7、水面 1、绿地 1、其他地点 6。
- 详细缺口见 `docs/map-data/江苏海洋大学苍梧手绘地图数据核查-2026-10-26.md`。

### 通灌

- 原始接口：<https://api.openstreetmap.org/api/0.6/map?bbox=119.179,34.583,119.190,34.592>。
- 原始响应：`docs/map-data/jou-tongguan-osm-2026-10-26.osm`。
- 应用数据：`public/maps/jou-tongguan.geojson`。
- 提取结果：7 个要素，校园面 1、未命名建筑轮廓 5、足球场 1。没有校内道路、绿地或水面记录。
- 一处跨越校园边缘的周边检察院名称面已排除，不作为校园地点。
- 五处建筑均未从手绘图补写名称；不能直接称为图书馆、教学楼或宿舍。

### 宋跳

- 原始接口：<https://api.openstreetmap.org/api/0.6/map?bbox=119.198,34.644,119.209,34.654>。
- 原始响应：`docs/map-data/jou-songtiao-osm-2026-10-26.osm`。
- 应用数据：`public/maps/jou-songtiao.geojson`。
- 提取结果：仅有校园面 1 个。该范围的当前 OSM 原始响应没有校内建筑轮廓，因此不能声称已经具备完整校园手绘地图。

## 可复现命令

`tools/extract-jou-campus-geometry.py` 只转换已保存的 OSM XML，不访问网络，不解释图片，不写云端。

```powershell
python tools/extract-jou-campus-geometry.py docs/map-data/jou-tongguan-osm-2026-10-26.osm public/maps/jou-tongguan.geojson --boundary 642920926 --name "江苏海洋大学通灌校区公开地图要素"
python tools/extract-jou-campus-geometry.py docs/map-data/jou-songtiao-osm-2026-10-26.osm public/maps/jou-songtiao.geojson --boundary 1365029657 --name "江苏海洋大学宋跳校区公开地图要素"
```

筛选规则：保留校园面；建筑、道路、运动场等几何至少有一个原始顶点在校园面内；跨边界道路保留原始完整几何，并标记 `campus_relation=crosses`。跨校园边界的周边命名站点不导入校园 POI。该处理并非几何裁切，也不能证明所有真实校内对象都已采集。

## 使用边界与后续资料

三个校区都可依据真实校园面切换和展示视野。苍梧可先完成有真实坐标的手绘样板；通灌只应用已有建筑和球场；宋跳先保留真实底图与校园范围。

参考图中的水彩质感、树木、屋顶和图标可以作为画风参考。新增建筑、道路、湖泊、楼名与校门需要有校方提供的带坐标图、公开许可的地理资料或现场核验依据，不能根据生成图片反推后冒充真实导航数据。

GeoJSON 均包含来源、许可、校园面 ID、原始查询范围和要素数。每个要素保留原始 `tags`、`osm_type`、`osm_id`，便于后续核对。

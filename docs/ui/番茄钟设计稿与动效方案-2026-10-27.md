# 哦狐番茄钟：界面设计与动效方案

## 设计目标

沿用森林绿、暖象牙白和狐狸橙，使用原有绿衣阿狐。首屏优先呈现剩余时间、当前状态和主操作；统计、待办、声音、计划及设置都继续使用现有真实数据。示意图仅用于讨论视觉方向，文字和数值不作为业务数据。

视觉概念图：`番茄钟概念设计-2026-10-27.png`。图中 4 次、100 分钟和 85% 均为生成图示例，底部导航也需按现有实际功能调整。该图不是应用截图，也不是最终素材。

## 页面布局

1. 顶部：返回、标题“专注”、深色模式入口；标题下面显示当天专注分钟、完成轮次和连续天数。
2. 主计时卡：状态标签，中心大号倒计时，进度环仅反映真实剩余时间；阿狐在卡片一角陪伴，不遮挡数字和操作。
3. 准备状态：15 / 25 / 45 分钟快捷选择、自定义设置和“设置并开始专注”。设置仍由现有面板处理。
4. 进行中：清晰显示专注或休息、暂停及结束按钮；暂停时展示继续按钮。计时以现有计时服务为准，动画不驱动计时。
5. 当前目标：可关联真实待办，用户自主选择是否完成待办；无目标时显示选择入口。
6. 声音和提醒：保留音频、铃声、勿扰与系统权限入口；失败时显示真实原因。
7. 底部导航：保留计时、任务、统计、设置；小屏确保滚动内容不被底栏遮挡。

## 动画分镜与素材清单

| 状态 | 阿狐动作及建议帧 | 触发和结束 |
| --- | --- | --- |
| 准备 | 看书、抬头、轻点头，建议 3 帧 | 首次进入播放一次，最后停在看书姿势 |
| 开始 | 放好书、坐正、进入专注，建议 4 帧 | 用户真正启动后播放一次，约 600–900 毫秒 |
| 专注 | 呼吸或眨眼，建议 2–3 帧 | 低频循环，每 8–15 秒一次；不干扰读数 |
| 暂停 | 停笔、抬头，建议 2–3 帧 | 暂停后播放一次；暂停期间保持静态 |
| 继续 | 点头、继续学习，建议 2–3 帧 | 恢复后播放一次 |
| 休息 | 合书、伸展、趴下休息，建议 4 帧 | 真实进入休息后播放一次，随后静止 |
| 完成 | 抬头、开心、轻举爪，建议 4–6 帧 | 只有计时真正完成才播放，约 1–1.5 秒；提前结束不显示完成 |
| 失败或权限受限 | 思考、指向提示，建议 2 帧 | 仅在相应真实错误出现时显示，文案给出可操作的解决方法 |

以上是待制作的动作分镜，不代表已有逐帧素材。当前素材包提供的不同姿势可以先用于静态状态和轻微位移；要实现连续自然的抽帧，需要另行绘制同尺寸、同锚点、透明底的连续帧。不要把各个互不连续的现成姿势冒充连续动画。

## 实现约束与验收

- 时间流逝、切后台、恢复、提醒和统计沿用现有实现；动画挂载或卸载不得重置计时。
- 遵循系统减少动态设置：显示静态帧，不循环、不抖动；播放失败退回静态图。
- 重点验收准备、专注、暂停、恢复、休息、完成、提前结束及权限失败；再检查 320px 窄屏、深色主题和系统字体放大。
- 真机检查前后台切换、通知、声音与耗电。动效不用于模拟通知成功或创建假的完成记录。
- 本文是设计稿与实现说明；完整番茄钟页面改版和新的连续帧素材尚待制作与验收。

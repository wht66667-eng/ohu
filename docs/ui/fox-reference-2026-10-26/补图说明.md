# 哦狐待补狐狸素材：实际截图与生成说明

截图时间：北京时间 2026-10-26。手机视口：390 × 844；另附 320 × 740 的服务/发布验收图。截图来自本地真实 React 应用，不是参考包的演示页面。当前为游客状态，空任务、空闲置、待核验美食和过期班车均如实保留。

本目录的 `verified-*` 是本轮已接入 V4/V7 的页面效果，用于统一风格；编号 01–11 是适合考虑补素材的位置。不是每块空白都要塞入狐狸：文字、表单、课表、地图点位与主要按钮优先。

## 统一风格

以附带的 `style-reference-brand-sheet.png` 为角色基准：橙色狐狸、暖白脸颊、深棕粗描边、森林绿上衣/书包、头顶小绿芽，保持同一脸型与比例。颜色参考森林绿 #1F5B3A、暖象牙白 #FFF8EB、狐狸橙 #FF8A3D。

优先生成透明底 PNG；人物和道具独立，不把文字、按钮、余额、课程或真实商家画进素材。人物单图建议 1024 × 1024；小场景建议 1536 × 1024。网页上的文案由真实 React 文字负责。请给完整的耳朵、尾巴、脚和道具留出安全边距，便于高质量抠图。

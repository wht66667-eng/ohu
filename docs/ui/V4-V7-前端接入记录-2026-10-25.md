# 哦狐 V4 / V7 前端接入记录

日期：2026-10-25。范围：学生端首页、服务、发布、校园广场、我的。

## 检查与页面映射

项目沿用 React 19、Vite 8、TypeScript 6、CSS Modules、motion/react 与 Capacitor 7。网页使用 BrowserRouter，安装包使用 HashRouter；保留 AuthProvider、PhoneShell、DialogLayer 和工作端门禁。

| 页面 | 参考 | 正式项目入口 | 保留的真实业务 |
|---|---|---|---|
| 首页 | V4 | `/` / HomePage | 课表归属校验、待办及提醒、校园动态、任务/闲置轮询、校区与自定义快捷入口 |
| 服务 | V4 | `/services` / ServicesPage | service-catalog 的 23 项服务、搜索分类、按账号隔离的本机最近使用、快递登录拦截 |
| 发布 | V7 | PhoneShell / PublishSheet | 朋友圈、任务、闲置、广场、求助的现有发布入口与关闭后导航 |
| 广场 | V7 | `/plaza` / PlazaPage | CloudBase 帖子、点赞、搜索、排行、公共聊天、图片、私聊、举报、删除与封禁规则 |
| 我的 | V7 | `/profile` / ProfilePage | 真实身份与角色、编辑资料、登录、管理条件入口及原有个人功能 |

CloudBase 单例仍由 `src/lib/cb.ts` 提供 cbAuth / cbRdb / cbStorage。未修改环境、凭据、数据库结构、云函数或存储权限。

## 实施计划与实现方式

1. 首页保留已确认的 V4 结构，提取与服务页共用的图标映射，纠正旧默认入口提示。
2. 服务页按 V4 重建品牌搜索栏、插画、快捷直达/真实最近使用、四格特色入口、六组紧凑分类；查询状态使用真实目录结果。
3. 发布按 V7 保留两列选择，复用 DialogLayer、原有五条目的路由和动画偏好。
4. 广场恢复 V7 左标题右操作、品牌横幅、图标标签与作者置顶的真实帖子卡；公共聊天保留独立滚动和输入区域。
5. 我的统一 V7 资料卡、快捷图标、行图标和分组；游客不展示虚构身份或统计。
6. 构建、Lint、既有发布/权限测试与浏览器逐页验证。验证结果追加至本文末尾。

可复用实现：`StudentServiceArtwork` 管理首页/服务图标；`ServiceEntry` 统一服务的快捷、特色、分类、结果四种呈现；`ProfileArtwork` / `ProfileRow` 统一 V7 行入口。沿用既有语义颜色、系统中文字体与约 18–23px 卡片圆角，不新增 UI 框架。

## 参考源码边界说明

V4 的原入口以 iframe 加截图热点预览为主，不能作为正式页面接入。V7 的帖子、计数、登录、上传为演示状态，未复制这些脚本。所有页面均使用正常 React DOM、真实文字、原有路由及业务处理。

课程、任务、日期、帖子与计数以真实返回或本机真实缓存为准。没有最近使用记录时显示“快捷直达”；空列表、失败、加载各自保留提示。

广场帖子目前没有独立评论接口；现有真实评论位于朋友圈 `moments_comments`。本轮保留朋友圈评论流程，没有添加虚构的广场评论数或假评论入口。

## 尚未接通的既有功能

- 其他学校的原生课表同步仍未接通，继续显示原有学校入口与说明。
- 校园卡没有开放余额/充值接口，仅保留官方导流。
- 图书馆没有已确认可外部嵌入的第三方预约入口，继续提供学校官方指引。
- 当前提供的校车表有效期已在 2026-04-30 结束，继续明确过期并关闭旧版本订阅。
- 附近美食仅展示已核验餐饮地点；候选市场、批发地点不冒充餐厅。
- 地图原有定位、标点、上传、审核和高德导航保持；真正手绘地理底图未在本轮重新制作。

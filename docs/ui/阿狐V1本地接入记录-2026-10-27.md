# 阿狐 V1 本地接入记录

## 当前范围

- 首发 16 款透明 PNG 已接入头像选择、聊天贴纸和表情图鉴；照片上传与裁剪入口保留。四张备用素材未放入首发选择列表。
- 三种启动封面随机展示；已确认的登录日期用于天数与表情，数据未确认时不编造天数。冷启动装饰最长约 3 秒，真实页面提前就绪可提前结束；从后台恢复不重复播放。
- 学生端慢速切页才显示加载提示；哦狐账号及课表同步的真实请求有各自的原位加载反馈，减少动态效果时保持静态。首页与我的页取消点击狐狸互动，页面继续使用原绿衣阿狐。
- Android 桌面变脸默认关闭，需在设置主动开启。显式退出或直接切换账号时清除前一账号的图标状态，保留本人选择的开关；系统前台切图可能等退到后台应用。

## 本地验收

- `npm run build`：通过；存在项目原有的 Capacitor 动态/静态混用提示。
- `node --test tools/fox-v1.test.mjs tools/launcher-mood.test.mjs tools/launcher-mood-native.test.mjs tools/boot.test.mjs`：49 项通过。包含日期、账号隔离、启动时间及桌面图标相关本地逻辑。
- `node .fox-v1-qa/login-check.cjs`：隔离浏览器验证账号登录等待、慢请求、减少动态、失败保留输入和重试；未接入真实账号和网络。
- 上课提醒相关本地自动检查 99 项通过；键盘、课表缓存和提醒宿主相关检查 45 项通过。原生提醒补丁经临时目录逆向和重新应用验证，重新安装依赖后仍可保留。
- 16 款头像/贴纸的隔离验收和截图见 `.fox-v1-qa/README.md`；启动封面的截图与预览地址见 `docs/ui/fox-v1-startup-2026-10-27/验收记录.md`。

## 需要继续核实

- 手机已安装的 1.2.136 是本轮这些后续改动之前的包。新的启动、登录动画、图标及提醒修复还未打包或在手机上验收；尤其需要测试划掉后台、锁屏、课前与开课两个阶段、声音及震动。
- 课表教务登录加载状态已接代码，但尚未以真实学校账号完成端到端验收。浏览器模拟不能代替真机输入法与云端接口验证。
- Android 系统图标更新受手机桌面和系统行为影响，尚未进行真实设备验收；iOS 原生桌面组件与图标变脸尚未实现。
- 其他页面旧素材的抠图仍需逐页视觉检查，不能认为所有素材已验收。

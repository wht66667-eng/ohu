核对日期：2026-11-01。以下区分源码、离线验证和真实服务验证；未部署新的接口或发布安装包。

| 服务能力 | GET `/api/integrations/capabilities` | 返回服务器实际开关；旧部署 404 或网络失败时页面明确提示服务未就绪 |
| 学习通 | POST `/api/learning/chaoxing/query` | 客户端、代理、课程/作业解析、本机保存及待办预览已实现；未使用真实账号验证、未部署；默认关闭 |

### 学习通数据流程

用户登录哦狐 → 输入自己的学习通账号密码 → 明确本次授权 → 代理登录学习通 → 读取当前课程列表 → 查询各课程作业 → 本机当前账号保存。

- 仅课程列表和作业状态；不做刷课、签到、作答、提交作业、代考或任务点伪造。
- 一次最多读取 12 门课程、全流程约 40 秒预算，剩余或失败课程显式列出；可在页面选择单门重试。
- 未知结构不会被当成“没有课程/作业”；未成功读取的课程保留旧作业。
- 截止日期缺少年份时保留待确认文字，不自行补年或安排提醒；转待办复用逐项确认面板和原提醒偏好。
- Cookie/密码只在请求内存中使用；不写磁盘。作业签名 URL 不返回或落入客户端存储。
- 此协议来自非官方开源适配，需要持续跟踪上游变化，不等同学习通官方合作接口。

### 体测来源证据与实际缺口

用户提供的 [jianghaidai-release v0.8.1](https://github.com/sunjingquan/jianghaidai-release/releases/tag/v0.8.1) 的源码 ZIP 仅有 `README.md` 和 `update.json`，README 明确主项目私有，仓库无开源许可证。因此没有复制酱海带的应用实现。

下载公开 arm64 APK 并核对 SHA-256：`de1dd5f4b5525a9366e551cbfae81f19dcfe279f067cfa4fe1af8d94291029a3`。只检查公开 URL 字符串，定位：

- `http://tice.jou.edu.cn:8080`
- `/student/studentFrame.jsp`
- `/student/queryHealthInfo.jsp`
- `/student/Historyhealth.jsp`

这些线索说明“没有固定体测站点”的早先判断不准确；它们也不能证明该站点当前从公网可用。当前电脑上 HTTP 8080、HTTPS 8080 和 HTTPS 443 均连接超时，DNS 解析到 `58.192.31.90`。没有提交真实账号、没有访问酱海带私有代理、没有绕过验证码或权限。

按用户反馈另做了绕过环境代理的直连检查，当前页与历史页仍为连接超时；未修改系统代理或 TUN 路由。体测客户端的学校会话设置 `trust_env=False`，避免继承不相关的海外环境代理，但这不能改变机器的全局网络路由。

体测适配独立实现 HTML 表单发现：只提交学校登录页中实际出现的用户名/密码字段和隐藏字段，限定同一学校源站，验证码仍需用户输入。未识别表单/成绩表时返回明确错误，绝不写入估算或空成功。真实 HTML 可能使用 JS 登录、其他字段或表格布局；需源站可达后校对，当前属于**待联调适配**。

体测同步仅在来源明确、操作员启用服务且用户同意查询后开放。该源 URL 使用 HTTP，服务器必须单独启用 `PHYSICAL_ALLOW_HTTP=1`，页面也明确告知并由用户勾选同意。没有关闭 TLS 校验或暗中降级。没有默认身份证密码、自动试密码或找回密码操作。

学校只提供年度而未提供具体日期时，保存年度且日期留空；不伪造为今天或某年 1 月 1 日。成绩批次先整体校验再一次写入，按来源与年度/日期更新，保留手工记录；支持 0–120 分，图表注明坐标。

## 部署与验证

新服务源码位于现有 `tools/jou-api`，保持原 `/api/timetable/*` 不变。安装新增固定依赖 `pycryptodome==3.23.0`，容器同时携带许可文件。

- `CHAOXING_READ_ENABLED=1`：开启学习通只读代理。
- `PHYSICAL_READ_ENABLED=1` 和 `PHYSICAL_ALLOW_HTTP=1`：在学校源站可达、确认表单适配及连接方式后才启用体测。
- 页面通过 capabilities 判断开关；部署网关需新增 capabilities、learning 和 physical 路由，不仅更新静态网页。
- 全部密钥/用户密码均不写入这些环境配置。用户密码仅来自本人在当前页面的一次输入。

已执行：Python 离线协议测试 7 项通过；Node 数据归属/原子保存/部分读取与原教务 HTTP 契约测试 14 项通过；Web 生产构建通过。没有使用真实账号、没有部署、没有发 APK/OTA。

下一步：让运行代理的网络能访问学校体测站，读取脱敏后的真实登录表单与成绩表完成适配；用本人测试账号完成成功、错误密码、验证码、历史年份和切换账号验收。学习通须验证真实课程、作业/截止日期、未开放作业的课程及验证挑战。其余服务按表中授权/接口依赖逐项推进。

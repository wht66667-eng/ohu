# 小米手机：划掉最近任务后继续上课提醒

2026-10-16，原生修复版 1.2.126（126）。

## 本次确认与修复

用户描述的操作是从最近任务划掉应用。尚未连接真实手机，不能确认具体小米系统限制和实际到达情况。

现有上课提醒已经交给 Android AlarmManager / 本地通知插件排程：当前安排未来 7 天，另保存最长 210 天课程快照，由原生接收器滚动补排。它不依赖网页定时器一直运行。自启动、精确闹钟、通知与电池设置入口已在应用中。

发现独立常驻通知仍在 KeepAliveService.onDestroy 中被主动删除。原生修复把系统服务销毁与用户关闭分开：

- 系统销毁服务或触发服务超时：不主动删除独立通知，也不改变用户开启偏好。
- 点击通知上的“关闭常驻”：删除独立通知并保存关闭偏好，防止下次重启又自动开启。
- 从应用内关闭：即使服务已经不在，也清掉可能残留的独立通知。

该修复针对通知卡生命周期，不代表已经证明小米系统会执行所有定时提醒。它需要安装新版 APK，界面热更新不能替换 Java 服务。

## 小米手机设置与验收

不同 MIUI / 澎湃 OS 版本菜单名称可能不同，可以从应用“设置 → 通知与提醒”进入已有的权限入口。

1. 允许哦狐发送通知；在“上课闹钟渠道”开启需要的声音、横幅、锁屏显示。
2. 允许“闹钟和提醒”（精确闹钟）。
3. 在手机应用管理中允许哦狐“自启动 / 后台自启动”。
4. 在小米应用省电管理中将哦狐设为“无限制”。Android 的电池优化豁免与小米自身省电限制不是完全相同的状态，都应核对。
5. 打开哦狐并同步一次课表，确认上课提醒开关、提前时间和已安排数量。
6. 点击“自检提醒”，安排 1 分钟后的通知，然后划掉最近任务并锁屏。到点后记录通知、声音与时间。即使常驻卡留下，也要以这次实际通知是否到达为准。
7. 再做一次真实课程提醒；重启场景使用单独的“3 分钟重启自检”，到点前重启并解锁。

如要保留应用内语音/页面弹层，可额外开启“常驻提醒通知”；这能请求前台服务运行，不保证小米系统一定保留进程。系统通知是独立通道。

没有一个通用权限能保证任何清理方式之后都保留通知或继续唤醒应用。系统设置中的“强行停止”、关闭通知权限、卸载或清数据属于不同情形，不能承诺继续送达。

## 云端备用方案：尚未接入

用户补充：需要覆盖其他品牌，正式方案不限定小米。应采用统一推送服务接入多厂商离线通道（例如个推或极光），由当前腾讯云后端统一调度。具体服务尚未选定、开通，不能把仅有云端定时器当作已经能送达各品牌手机。

用户已确认目前仅私下分发 APK，尚未上架。因此当前先交付不依赖商店资格的本机系统排程修复；跨品牌云端通道尚不具备统一上线条件，不声称已接通。不同设备仍需通知/精确闹钟/厂商后台权限和真机验收。

接入前必须核对应用上架状态和厂商资格。根据查询时的个推官方条件，小米、vivo 与 OPPO 正式厂商通道需要上架应用商店；未上架应用可用范围需逐厂商核实。聚合服务不消除这些要求。纯鸿蒙系统还需要单独的鸿蒙应用，当前 Android APK 不能直接覆盖。

跨品牌实施顺序：确认发布状态与开发者资质 → 选择并开通聚合服务 → 注册已具备资格的各厂商通道 → 集成原生 SDK 与设备绑定 → 实现云端任务、撤课和去重 → 各品牌真机验收。未取得凭证前不添加无法初始化的推送 SDK，也不在界面显示“云端提醒已开启”。

参考：[个推通道条件](https://docs.getui.com/getui/scene/pushCondition/)、[个推多厂商能力](https://docs.getui.com/getui/start/advance/)、[极光厂商参数申请](https://docs.jiguang.cn/jpush/client/Android/android_3rd_param)。

适合小米的备用路径为：云端保存已授权的课表与提醒偏好 → 定时触发任务 → 小米推送通知栏消息 → 手机系统显示。该路径需要网络，也受推送平台与系统权限限制，不替代本机准点提醒。

当前项目没有注册小米推送 SDK、设备 RegID 或云端发送凭证。正式接入需要：

- 为学生包名 `com.sunshinecampus.app` 开通小米开发者推送应用，核实当前接入资格与通知分类。
- 客户端配置平台提供的 AppID/AppKey；服务端发送凭证仅保存在云端环境变量，不放进 APK、网页或日志，也不要在聊天中粘贴。
- 经用户授权绑定设备 RegID 与真实账号，支持退出解绑与令牌更新；服务端校验账号归属。
- 定时任务处理时区、课表变更和撤课，按账号/课程实例/提醒时点去重，限制过期消息，处理无效设备与失败重试。
- 本地与云端双通道需制定跨进程去重办法，不能仅凭网页中的标记承诺没有重复通知；完成真机锁屏、划掉、断网恢复、切账号与撤销授权验收后再上线。

本轮没有开通或部署云端推送，没有上传个人课表，也没有改动云端数据。

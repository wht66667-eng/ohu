## 0. 一句话结论

项目里**已经有一套完整的狐狸资产 + 变脸逻辑**（`public/sunny-fox/` 13 张表情 + `engagement.ts` 阈值引擎 + `app-icon.ts` 桌面换图标 + `AwayLoginHost` 缺勤弹窗），但**只在 3 处露出**（桌面图标、缺勤弹窗、工作端门禁）。

本次要做的是把这只狐狸**从「桌面图标」升级为「全 App 的在场角色」**：

1. **全域挂载**——每个页面、每个空状态、每个成功/失败瞬间都有一只小狐狸在场（固定位 + 内联位 + 瞬态位三层）；
2. **变脸贯通**——桌面图标那套「连击 / 缺勤」表情，现在**同步出现在 App 内所有狐狸位**（同一只狐狸，同一个表情）；
3. **多邻国式情绪**——登录越久表情越兴奋，越久不来表情越委屈，形成「不忍心让它失望」的黏性。

## 2. 设计原则（三条红线）

### 原则 1 · 狐狸是「在场角色」，不是「贴纸」

不搞「每个卡片角落贴一只小狐狸」的堆砌。狐狸承担**情绪传达、状态指示、引导陪伴**三个职能，出现在有情绪语义的位置。

### 原则 2 · 一狐一表情，全局同频

App 内所有狐狸位共用 `getEngagementSync()` 的同一份快照 → **同一只狐狸**。用户在首页看到它委屈，进番茄钟它还是委屈，打卡后全局一起变开心。这才有「一只狐狸陪着我」的代入感，而不是「满屏狐狸贴纸」。

### 原则 3 · 不抢主任务，不占决策面积

- 常驻位只在**无遮挡区域**（顶部留白、卡片间隙），不压按钮、不盖内容
- 大表情只在**情绪节点**出现（打卡成功、连续达标、缺勤回归、空状态），单次停留可关闭
- 一律遵守 `prefers-reduced-motion`，动效可关

## 3. 三层挂载架构（核心方案）

### 第一层 · 常驻在场位（EngagementHost）

**一个全局组件，挂一次，全站生效。**

```
src/components/fox/FoxPresenceHost.tsx   ← 新增
```

| 项 | 规格 |
|---|---|
| 挂载点 | `PhoneShell` 内，`<>` 顶层，与 `AwayLoginHost` 同级 |
| 位置 | 底部 TabBar **上方右侧**浮岛位（`right: 14px`，`bottom: calc(var(--tab-h) + 12px)`） |
| 尺寸 | 40×40 头像（= 表情 512px 缩略） |
| 形态 | 圆形玻璃拟态底座 + 表情头像 + 微呼吸动效（3.6s `translateY(-2px)`） |
| 交互 | 点一下 → 弹出「狐狸面板」（表情大图 + 当前档位台词 + 连击天数 + 下次变化提示） |
| 隐藏规则 | ① 沉浸式番茄钟运行中隐藏 ② 登录/注册页隐藏 ③ 滚动到底部时降到 `opacity: .55` 不挡内容 ④ 工作端可配置是否显示 |
| 层级 | `z-index: 60`（低于 TabBar 弹层 100、低于弹窗 200） |

> **收益**：这是唯一一个「每一屏都看得到」的狐狸位，是变脸效果的主力展示面。

### 第三层 · 瞬态情绪事件（FoxMoment）

**「变脸那一秒」必须让用户看见**——这是多邻国的精髓。

```
src/components/fox/FoxMoment.tsx         ← 新增
```

| 触发事件 | 表现 | 时长 |
|---|---|---|
| 今日首次打卡（连击 +1） | 底部弹入小卡：表情从昨→今**过渡动画** + 「连击 3 天 · 势头不错！」 | 2.6s 自动收 |
| 连击达成里程碑（3/7/14） | 全屏轻遮罩 + 表情放大弹入 + 彩带粒子 + 台词 | 点任意处关闭 |
| 缺勤回归（away → streak） | 从委屈表情**逐帧过渡**到开心表情（复用 AwayLoginHost 帧动画思路） | 3.2s |
| 番茄完成 | 右下角表情头像 + 「+25 分钟」 | 2.2s |
| 交卷完成 | 表情 + 得分 | 3.0s |

**过渡动画实现**：两张表情图叠加，`opacity` 0→1 交叉淡入 600ms + `scale` 1→1.08→1，不用逐帧序列（省体积、够自然）。

## 4. 多邻国式变脸机制（核心竞争点）

### 4.1 情绪曲线设计

多邻国的核心不是「换个图标」，而是**情绪梯度**——用户能感到「它在等我 / 它在失望 / 它生气了」。

| 阶段 | 天数 | 表情 | 语气 | 设计意图 |
|---|---|---|---|---|
| 蜜月期 | 连击 1–2 | 微笑看远 | 鼓励 | 建立习惯 |
| 上升期 | 连击 3–6 | 大笑挥手 | 表扬 | 正反馈 |
| 高光期 | 连击 7–13 | 比赞 + 阳光 | 骄傲 | 舍不得断 |
| 巅峰期 | 连击 ≥14 | 燃烧 + 彩带 | 亢奋 | 「燃起来了」 |
| 微提醒 | 离开 2–4 | 望向远方 | 轻轻戳 | 低压力召回 |
| 担心期 | 离开 5–11 | 耷拉耳朵 | 委婉 | 「你可以的」 |
| 委屈期 | 离开 12–19 | 眼眶含泪 | 示弱 | 「别放弃」 |
| 想念期 | 离开 20–24 | 抱着救生圈发呆 | 撒娇 | 「想你了」 |
| 焦急期 | 离开 25–29 | 抓头 / 转圈 | 催促 | 「快点回来！」 |
| 临界期 | 离开 ≥30 | 崩溃 / 生气 | 最后通牒 | 「最后机会」 |

> 现有 13 档资产**已完美覆盖这条曲线**，无需改档位。

### 4.2 三处联动（关键：一个状态，三个载体）

```
        用户打开 App / 打卡
                │
                ▼
      engagement.ts 状态机
      （streakCurrent / awayDays → iconState）
                │
      ┌─────────┼──────────┬──────────────┐
      ▼         ▼          ▼              ▼
  桌面图标   App 内常驻位  页面内联位   瞬态变脸动画
 （原生层）  （第一层）   （第二层）   （第三层）
  activity-alias  FoxPresenceHost  FoxInline  FoxMoment
```

**关键改造**：让 `engagement.ts` 的每次状态变更**广播事件**，三层同时响应——

```ts
// src/lib/engagement.ts 新增
window.dispatchEvent(new CustomEvent('fox-state-change', { detail: eng }))
```

`FoxPresenceHost` / `FoxInline` / `FoxMoment` 统一监听 `fox-state-change` → 用 `useSyncExternalStore` 或 `useEffect` 订阅，**保证同屏所有狐狸表情严格一致**。

> 这也顺带修掉 `StreakBar` 现有的事件监听（它监听的是 `focus-stats-change`，不是 engagement 的）。

### 4.3 道具化「狐狸日记」（可选加分项，不占本期必做）

个人中心新增「狐狸日记」入口：

- 一条时间线，记录表情变化历史（哪天变委屈、哪天回归、哪天巅峰）
- 底部「12 张表情全集」图鉴，未解锁的置灰
- **零后端**：状态已在 `sc.engagement.v1` localStorage 里，追加一个 `sc.fox.journal.v1` 即可

> 这条建议先做**图鉴**（纯展示，1 小时工作量），日记时间线放二期。

### 4.4 数据层（本期不动后端）

| 项 | 结论 |
|---|---|
| 存储 | 沿用 `localStorage: sc.engagement.v1` + `sc.fox.journal.v1`（新增） |
| 云端 | 沿用现有 `checkins` / `user_engagement` 表的**尽力同步**（离线可用） |
| 新表 | ❌ 不需要 |
| 新云函数 | ❌ 不需要 |

# OHU 哦狐 · 长期免费与可持续运营公约 V1.0

生效版本：V1.0  
整理日期：2026-10-31  
适用范围：哦狐学生端、管理端、官网、开源项目及后续运营安排。

## 核心承诺

**核心校园功能，长期免费。**  
**运营成本，每月公开。**  
**资金优先保障基础服务。**

社区自愿支持 · 外部资金支持 · 官网公开赞助 · 开源共同建设

## 一、固定规则

1. **核心校园功能长期免费。** 不设置会员，不设置基础功能付费墙。第三方学校系统、网络、云服务或其他供应方可能存在独立费用与可用性限制；哦狐不承诺第三方服务永久免费，也不把外部收费伪装为哦狐收费。
2. **每月公开详细收支。** 官网按月发布已经核对的收入、支出类别、用途与期末基础运营储备。没有完成核对和发布的月份标记为“尚未发布”，不得用估算、样例或虚构数据填充。
3. **赞助展示只在哦狐官网。** App 内不展示赞助商、商业广告、推广位或赞助入口。官网合作展示须明确标注合作性质，不以赞助换取 App 内曝光或影响功能排序。
4. **资金使用先保障基础运营。** 优先建立服务器、数据库、备份、安全、域名及必要维护的储备金。基础服务保障后，再安排开发投入。每月报告应呈现实际支出分类与储备变化，不公开个人敏感财务信息。
5. **支持完全自愿。** 赞助不购买功能、会员、特权、数据访问或审核优先权；不支持 App 内线上支付、资金托管或平台代收款。
6. **不出售用户数据。** 不向赞助方提供个人数据，不以赞助或合作为由扩大数据收集。
7. **开源共同建设。** 以实际公开仓库、许可证、文档和贡献记录为准。未开放的接口、未部署的服务、未核验的功能不得宣传为现成能力。

## 二、官网页面要求

- `/download/transparency.html`：公开经核验的月度收支报告；没有报告时显示空状态，不展示虚构账单、金额或图表。
- `/download/partners.html`：展示已确认的合作伙伴；尚无已确认合作时明确说明，不放占位品牌或假标识。
- `/download/support.html`：说明自愿支持原则、资金用途和当前已核验的支持渠道。渠道未核验前不放个人收款码或未经确认的收款链接。
- `/download/about.html`：说明开发初心、长期免费原则、开源理念、运营成本和本公约。

所有页面都要说明哦狐是独立校园项目、非高校官方应用，并区分已核实事实与计划。

## 三、月报内容与隐私

每月详细报告至少记录：报告月份、各项收入类别及核验金额、各项支出类别及核验金额、资金用途、期初与期末基础运营储备、差异说明。报告由实际收据、账单或可审计凭据核对后发布；对外展示时去除个人身份、账号、支付凭据和其他不必要的敏感信息。报告未核实完成时显示“尚未发布”，不得用 0、估算值或示例记录替代。

## 四、资金优先级

1. 保障线上基础服务运行与必要的服务器、数据库、备份、安全和域名成本。
2. 补足合理的基础运营储备金，降低服务中断风险。
3. 在基础保障满足后安排开发、测试、无障碍和体验改进。
4. 所有支出纳入当月报告，并简述用途。

## 五、修改公约

本 V1.0 中已确定的规则不是 Codex 可自行改变的设计变量。修改须由项目负责人明确提出，并发布新的版本、变更日期和变更说明。实现时以本文件为依据；官网、客户端或运营流程与公约冲突时，应修正实现并记录。

# 哦狐朋友圈图片编辑实施记录

日期：2026-11-04。范围：本轮用户指定的朋友圈选图、深色编辑器、画质处理、免费商用字体、涂鸦马赛克和贴纸。源码实现与本地验证已完成；不是线上发布记录。

## 已实现

- 相册选图后直接进入发布草稿，最多9张，点击照片才进入编辑；三列缩略图、移除、前后移动和拖动排序、独立预览。白图补齐默认关闭，可选开启；未发表前不上传。
- 编辑器采用全屏深色画布，底部工具栏；裁剪、90度旋转、水平翻转、原图对比、恢复原图、撤销／重做。编辑完成后保留对象层，重新进入仍可调整文字和贴纸。
- 可变粗细彩色涂鸦、框选马赛克及格块强度、可移动缩放旋转的图片贴纸；新增12款本地Noto Emoji静态SVG贴纸。Fabric.js为对象画布与涂鸦底座，react-easy-crop负责裁剪；马赛克由哦狐实现，没有复制不明许可项目。
- 字体：系统黑体／宋体，以及站酷快乐体、站酷小薇体、龙藏手书三款OFL 1.1中文字体。随包保留版权、完整许可、来源及哈希；按选择加载，15秒超时可重试；撤销和导出前恢复字体。
- 独立图层可选择、隐藏、调整上下顺序／透明度；正常、正片叠底、滤色、叠加四种混合模式。裁剪、旋转与水平翻转会合并图层，但可以撤销。
- 真实二维FFT去噪／模糊／锐化，三级正交Haar小波软阈值去噪／细节增强，中值去斑、Sobel边缘、浮雕；8种滤镜，曝光、亮度、对比度、饱和度、色温、伽马、暗角7项调节；支持本机保存一组常用数值参数。没有把CSS预览当成导出效果。
- 画质处理运行在Web Worker，可停止、超时退出；FFT采用带镜像边界的重叠分块，限制内存。输出最长边1600，单张选择20 MiB以内，40个对象、最多12步且16M字符的撤销历史预算。
- 新增Capacitor Camera原生相册适配；未安装该插件的旧APK和网页回退文件选择器。Android依赖已更新；iOS构建工作流补相册用途描述。

- `node --test tools/moment-photo-quality.test.mjs`：11项通过，包括恒定像素／alpha保持、非幂次与单像素边界、高频抑制、锐化、小波效果、FFT分块接缝、非法参数拒绝。
- `npx tsc -b --pretty false` 与 `npm run build`：通过。编辑器独立懒加载，构建约313 kB（gzip约98 kB）；保留工程已有动态导入警告，未宣称消除全站告警。
- `.codex/qa/moments/browser_check.py`：Chrome 390×844视口10组通过、页面运行错误0。覆盖裁剪、旋转撤销、文字／图片贴纸重开、画笔、真实Worker滤镜、发布草稿、字体／图层、马赛克和小波参数导出。使用本地合成测试图片，没有调用真实发表接口。
- `.codex/qa/moments/asset_check.py`：三款字体实际解码及12个SVG实际加载通过；截图位于同目录。
- `npm audit --omit=dev --json`：生产依赖漏洞0（本轮安装后检查）；不等于完成全项目安全审计。
- `npx cap update android`：成功发现Camera 7.0.5。没有构建APK或运行Android真机。

# 哦狐官网 V4：源码审查与实施计划

日期：2026-11-01。依据用户提供的 V4.0 规划，保留现有官网及其真实数据来源，渐进改造。

## 审查结果

- 官网位于 `public/download/`，首页是 `index.html`、`product-site.css` 和 `product-site.mjs`；现有项目为 Vite/React，官网本身是独立静态页面，无需更换技术栈。
- 已有 12 个功能模块目录、产品模拟器与触摸滑动、三校区地图、狐狸情绪切换、安卓／iPhone 安装入口、迭代页、关于、开源、财务、合作伙伴与支持页面。
- 素材包含阿狐立绘和产品真实截图。当前首页视觉偏暖白，舞台氛围和移动导航层次尚可增强；交互已有基础，需保留现有链接与状态。
- 地图的高德底图依赖 Key 与代理；财务报告、合作伙伴及贡献者须有真实资料，缺失时保持现有明确空状态。
- 当前官网仍含 iPhone 既有指南；本轮 V4 不新增签名或发布流程。下载地址以现有发布清单为准。

## 实施顺序

1. **舞台与导航**：在现有页面及样式上构建深森林绿首屏，强化聚光灯、阿狐、真实设备截图和下载入口；滚动进入暖白世界。移动端独立排版，保证菜单及下载入口可触达。
2. **交互与动效**：增加可关闭的开场动效、滚动进度、轻量鼠标视差与产品展示反馈；保留原有产品模拟器、键盘与触摸、地图和下载交互。支持减少动态效果，动画失败时内容仍可见。
3. **其余页面与内容**：沿用现有功能、故事、校园、开源、透明度与下载页面；逐步统一视觉，不编造财务、合作方、贡献者或服务状态。
4. **交付检查**：构建并检查桌面、移动端与关键交互；记录真实检查结果和外部依赖。发布到公网依照现有部署条件单独执行。

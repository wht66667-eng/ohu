# 哦狐项目总设计与官网发布方案

更新时间：2026-10-31  
当前源码与已发布基线：**1.2.145 / build 145**。本文件把产品结构、代码边界、官网域名、Android 安装包、iOS IPA 及发布状态放在一处，避免把计划、源码和线上状态混为一谈。

## 1. 产品定位

哦狐是面向高校学生的校园生活工作台，主线是把“课程安排—学业任务—校园生活—同学协作”放进一个可持续使用的应用。学生端与管理端共用项目代码，但分别构建、分别控制权限。狐狸角色是品牌陪伴层，不能遮挡或替代主要功能操作。

## 2. 功能与代码架构

| 产品域 | 学生可完成的主流程 | 主要代码边界 | 关键依赖 |
|---|---|---|---|
| 校园工作台 | 查看今日课程／待办／公告，进入常用服务 | `src/pages/HomePage.tsx`、`src/pages/schedule/` | 账号、课表数据、公告服务 |
| 学业中心 | 课表、成绩、考试、体测、学习资料与专注 | `src/pages/study/`、`src/pages/StudyHubPage.tsx`、`src/lib/` | 教务适配、CloudBase、AI 网关（AI 功能） |

| 校园服务 | 搜索服务、官方入口、个人常用链接 | `src/pages/ServicesPage.tsx`、`src/lib/service-catalog.ts` | 外部学校／校园服务 |

| 碰个空 | 填空闲时间与活动意向，邀请／匹配、组队并确认活动 | `src/pages/MeetPage.tsx`、`src/lib/meet-api.ts` | 活动 API、匹配数据、审核与举报 |

技术主干为 React、TypeScript、Vite、Capacitor、CloudBase Auth/PostgreSQL/对象存储，以及江苏海洋大学教务适配服务。前端页面只能表达交互，账号权限、审核、配对约束和数据隔离必须由后端与数据库策略强制执行。更多产品和架构现状见[实际项目设计与实施方案](./哦狐_实际项目设计与实施方案.md)及[服务目录](../architecture/service-catalog.md)。

APK 与 OTA 不得互相替代：APK 更新原生壳／插件；OTA 只更新兼容当前原生壳的网页资源。发布前由 `npm run release:prepare -- --reuse-apk --min-native-build 144` 重新生成校验包、官网暂存资源与最终清单；发布使用 `npm run release:publish`，最后再逐条核对线上清单与文件哈希。

### iPhone IPA

## 5. 发布清单与检查

### 单一版本身份

`package.json`、`src/lib/app-version.ts`、Android Gradle、Capacitor、APK 元数据、OTA manifest、`source-identity.json` 与 iOS manifest 应共享同一版本／构建号。任何一个身份不一致，都停止发布；不手改线上状态为“可下载”。

### 每次发布的顺序

1. 更新版本与发布说明，确认工作区无密钥、个人数据或测试账号。
2. 构建并核验学生端／管理端 APK；复用旧 APK 时也必须确认其版本与本次源码完全相同。
3. 生成学生端／管理端 H5、OTA bundle、下载页暂存与 manifests。
4. 上传 APK 和 OTA 字节；随后上传网站资源；最后上传发现清单，避免客户端提前读到尚未上传的包。
5. 从公网读取版本清单、两端 OTA manifest、APK／IPA manifest、首页和下载页面，验证 HTTP 状态、身份、长度与 SHA-256。
6. 记录源码、构建、上传、线上核验、真机验收各自状态。某一项没做就明确标记未验证。

发布命令与详细约束以 `tools/prepare-release.mjs`、`tools/publish-release.mjs`、`.github/workflows/ios-build.yml` 为准。CloudBase 上传成功不代表数据库迁移、云函数、AI 服务或手机实际安装已通过验收。

## 7. 操作入口

- 版本准备：`npm run release:prepare -- --reuse-apk --min-native-build 144`
- 发布：`npm run release:publish`
- 仅查看发布上传计划：`npm run release:publish:plan`
- iOS 构建：GitHub Actions → **Build unsigned iOS IPA**
- 本地 IPA 复验：`python tools/verify-ios-ipa.py --ipa <IPA路径> --manifest <清单路径> --version 1.2.145 --build 145`

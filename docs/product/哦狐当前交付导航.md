## 4. 哦狐插件

入口为 **服务 → 哦狐插件**（`/plugins`）；“我的 → 哦狐科技”也可管理。

| 插件 | 创作者与标识 | 使用方式 |
| --- | --- | --- |
| 专注计时 | 哦狐官方 | 快速进入现有专注页 |
| 课程提醒 | 哦狐官方 | 快速打开课表和提醒设置 |
| 今日塔罗灵感 | `wft` · 非官方 | 本机抽取自我反思提示 |
| 星座今日灵感 | `wft` · 非官方 | 选择星座，查看本机生成的娱乐提示 |
| 生日数字趣玩 | `wft` · 非官方 | 当前页面临时计算，输入不保存、不上传 |
| 今日记忆卡 | `wft` · 非官方 | 复用当前账号的单词计划与复习记录 |
| 题库五题快测 | `wft` · 非官方 | 本机题库随机抽最多五题，即时练习 |

新用户的五项非官方插件默认关闭，主动启用后才能操作；已有明确选择会保留。启停和个人星级按账号保存在本机。停用会卸载插件操作区域并清空该次临时交互；停用“课程提醒”快捷插件不会取消已安排的课程通知。

插件随 Web／APK 静态打包。GitHub 项目展示用途、来源和许可；同类轻量模块复用哦狐自身数据层。作者按[插件格式](../plugins/ohu-plugin-format.md)与[创作者工作流](../plugins/ohu-plugin-creator-workflow.md)提交公开仓库方案，经管理员审查后由维护者接入并随版本发布。

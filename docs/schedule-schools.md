# 多校课表查询

本地准备版本：1.2.128。入口核对日期：2026-10-20。尚未发布至线上。

在“课表”顶部选择学校。默认江苏海洋大学，选择会在本机记住；`/schedule?school=nmukd` 等链接也可直接进入对应学校。

用户已明确要求在哦狐输入学号密码并显示个人课表。核查后确认这四校尚未实现同步适配，因此首屏已更正为“本校课表同步尚未接通”，不把网页跳转称为绑定或同步。官方链接、网络切换与说明收进“临时查询：学校官方入口”；临时链接改为同页导航，不依赖新窗口。没有添加无法实际提交的学号、密码或验证码表单。完整接入的差距与验收条件见 [接入审计](school-sync-audit.md)。

## 查询方式

| 学校 | 本轮功能 |
| --- | --- |
| 江苏海洋大学 | 保留原有学号、教务密码、验证码、自动同步、已缓存课表、成绩和考试功能，仅增加学校选择控件。原教务接口与地址未更改。 |
| 南京医科大学康达学院 | 提供校外 WebVPN、校内学院主页与教务课表下载专区。按学校通知，经网上办事大厅进入教学综合信息服务平台，再查询个人课表。 |
| 连云港师范学院 | 新核实学校公布的校内教务地址；提供外网“喜鹊儿”使用指引。具体课表菜单需要本校账号确认。 |
| 连云港职业技术学院 | 使用学校通知公布的树维教务域名，补充“我的连职院”查询方式；提示相关校园网络访问条件。 |
| 江苏财会职业学院 | 提供树维教务入口和统一身份认证说明；账号密码按学校当前通知处理，不固定展示未核实的初始密码规则。 |

其他四校为官方网页/App 查询入口与操作说明，本轮没有为其实现教务接口适配。外部查询结果不会自动导入哦狐，也不会生成本机上课提醒。切到这些学校时，不挂载海大的验证码、凭据表单或课表缓存视图，不向海大的查询接口发送其他学校账号。

操作支持打开官方页面、复制查询步骤与地址、展开来源与核对日期。外部系统使用学校自己的登录页面；哦狐不收集这四校的教务或 VPN 凭据。

- 连职：[教务处通知](https://www.lygtc.edu.cn/jwc/info/1115/1585.htm)确认 `jw.lygtc.edu.cn/eams/sso/login.action`；[学校官方 App 介绍](https://www.lygtc.edu.cn/info/1014/8576.htm)确认“我的连职院”可查课表。通知中的无线网或 5G 专网要求针对相关教务服务，不推断所有功能都必须内网。
- 财会：[智慧校园中心通知](https://www.jscfa.edu.cn/zhxyzx/2023/0211/c1222a25734/page.htm)确认教务地址；[当前教务入口](https://jw.jscfa.edu.cn/eams/sso/login.action)会跳转学校统一身份认证。

## 验证与产物

以下 548 项测试与热更新准备属于前一次网页入口版本，不能作为真实多校同步的验收依据。此次状态修正已重新通过 TypeScript、网页构建、40 项课表相关回归及 390/1024 宽度浏览器检查；原海大绑定表单仍可用，其他学校不显示凭据输入框、不请求海大验证码。

当前内置浏览器点击康达 WebVPN 链接已经触发同页导航，但学校站点连接关闭；浏览器自动错误页被工具 URL 策略阻止读取，因此不能将这次操作标为成功进入学校系统。正常匿名会话 GET 与浏览器可达性是不同证据，详见 `.codex/qa/nmukd-entry-audit.json`。未尝试绕过学校或浏览器限制。

- 全量 548 项测试通过。新测试覆盖学校默认值与存储失败、合法官方域名、深链接、其他学校不挂载海大同步组件、切换保留 URL 其他参数。旧课表节次编辑与账号隔离测试继续通过。
- TypeScript 检查、网页构建、学生与管理端热更新构建通过。热更新最低原生版本为 126。
- 本地隔离浏览器：390/1024 宽度、五校页面、学校切换、刷新与选择记忆、复制查询步骤、原海大绑定表单；未出现页面错误或横向溢出。其他四校没有发起海大验证码请求。已查看浅色、深色截图并修正新页面的深色背景与主按钮文字颜色。
- 简化后的补充验收：首屏说明默认关闭；康达/师范校内外切换同步更新主链接和提示；展开、复制、再次收起均可用。通过真实主题接口切换并等待稳定后，深色页面、卡片、文字与对应颜色变量一致。
- 定向代码检查无错误；原课表页有两处既有 Hook 依赖警告，本轮没有改变相应业务计算。
- 未使用真实学校账号登录；校内/VPN 可达性与具体账号权限仍需对应学校用户验证。浏览器截图不是 Android 真机外链跳转证据。
- 本轮仅本地准备，不上传网页、APK 或热更新，不改云端数据。

此前准备的学生热更新 `.ota-out/prepared/user/1.2.128-128/manifest.json` 与管理端 `admin` 目录已落后于此次源码修正，不可直接作为当前版本发布；本轮没有重新准备或发布 OTA。检查记录在 `.codex/qa/school-*`。

# Agnes AI 服务端配置

该云函数为哦狐提供 9 种 AI 能力：校园问答、学习计划、资料摘要、考点提炼、自测题、作业拆解、考前复习规划、词汇讲解、课表通知解析。所有能力共用服务器侧密钥池并在每次请求时选择一把密钥；密钥不会进入网页包或 APK。Agnes 凭据只保存在 CloudBase 云函数环境变量中；不要添加 `VITE_` 前缀，也不要提交密钥。

## CloudBase 云函数环境变量

- `TCB_ENV`: `jou-d4gq7a3cqf51e6caa`
- `CLOUDBASE_APIKEY`: CloudBase 服务端访问密钥，用于共享数据库限流。
- `AGNES_API_KEYS`: JSON 字符串数组，例如 `["新密钥一","新密钥二"]`。函数会在服务端轮换选择并在密钥失效或限流时尝试池内下一把；也可只配置 `AGNES_API_KEY` 单个密钥。
- `AGNES_API_BASE_URL`: `https://api.agnes-ai.cn/v1`
- `AGNES_MODEL`: `agnes-2.5-flash`

用户主动提交的内容仅随当前请求发送给 Agnes，用于生成当次回答；函数不会把输入或回答写入数据库或日志。请求要求有效的非匿名 CloudBase 登录态，并通过共享数据库限流：每用户每分钟 8 次、每天 120 次。没有 CloudBase API Key 或共享限流不可用时，功能保持关闭。

## 发布前配置

1. 在 Agnes 控制台撤销聊天中暴露过的旧密钥，创建新密钥；将新密钥只填入 CloudBase 云函数的环境变量。
2. 确认 CloudBase 环境已应用 `rate_limit_hit` RPC 及其限流表（现有 `examGenerator` 已使用相同限流机制）。
3. 部署 `agnesAi` 云函数，并应用该目录的 `_route.json` 网关路由。
4. 发布前在已登录测试账号中逐项验证 9 种功能、超额限流和未配置服务时的提示；课表通知解析要覆盖停课、整日补课、单门课程变动和不明确日期，并确认任何 AI 结果都须用户预览后再保存。

本地静态网页/安装包不含 API Key。仓库配置只登记云函数名称，不包含密钥值。

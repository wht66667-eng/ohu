## C1. 主页三点菜单 → 浮层菜单

```
把 src/pages/HomePage.tsx 顶部的 `···` 三个点的 <span> 换成
SVG 三点菜单图标（自绘，20×20，圆点横排）。点击展开一个
position: absolute 浮层菜单，4 项：首页、课表、待办、我的，
点击跳转对应路由。菜单项用 var(--card) 背景 + var(--shadow)
+ 圆角 12px。点击外部关闭菜单。
```

## C2. 待办左滑删除

```
在 src/pages/TodoPage.tsx 列表项 .item 上加左滑手势：
横向滑动超过 60px 时露出右侧的红色「删除」按钮（红色背景
+ 白色 🗑 图标）。轻触列表项仍走编辑逻辑。松手后：
  - 滑动距离 < 60：弹回原位
  - 滑动距离 ≥ 60：停在删除按钮可见位置
  - 点击删除按钮：触发删除
  - 点击右侧区域或滚动：自动收回
使用 transform: translateX 实现，touch + pointer 事件兼容。
不引入第三方库。
```

## C3. 新建待办快捷键提示

```
在 src/pages/TodoPage.tsx 的 PageHeader right slot（"+ 新建"
按钮）右侧加一个小气泡 ⌘N / Ctrl+N 提示（仅在宽度允许时
显示，气泡是圆角小标签，灰底浅文字）。监听键盘事件：
⌘N（mac）/ Ctrl+N（windows）触发 openNew()。当焦点在
input/textarea 内时不要拦截。
```

## C4. 主页「我的待办」卡片加完成进度环

```
把 src/pages/HomePage.module.css 的 .todoCard 右侧的
.todoBadge 数字角标，改为 SVG 圆环进度指示器：
  - 圆环直径 28px，stroke-width 3px
  - 背景圆：var(--line)
  - 进度圆：var(--green)，旋转起点 12 点钟方向
  - 圆环内：居中显示今天+逾期的数字（小字 10px）
进度 = 今天已完成 / 今天应完成（如未设置「应完成」，直接
显示数字）。当数字 = 0 时隐藏整个圆环，只保留右箭头。
```

## C5. 待办临期提醒弹窗加「稍后再提醒」

```
在 src/pages/HomePage.tsx 的临期提醒弹窗（.remindSheet）的
「知道了」和「去处理」按钮之间，加一个「10 分钟后再提醒」
的中间按钮（ghost 风格，更小）。点击后：
  - 关闭当前弹窗
  - 在 localStorage 'todo.snooze' 写入 { id, until: now+10min }
  - 10 分钟后再次进入首页或前台时，检测到 until 已过则重新
    弹出该条提醒（仅 1 次）
按钮文案：⏰ 10 分钟后再提醒
```

## C6. 主页「任务&二手最新」模块换紧凑双列

```
把 src/pages/HomePage.tsx 第 214-247 行的「任务&二手最新」
.list 模块，从单列横排改为双列网格（grid-template-columns:
1fr 1fr; gap: 10px）。每张卡片包含：缩略图（60×60 圆角 12px）+
「求助/二手」小标签 + 标题（最多 2 行省略）+ 灰色 sub（位置/类目）
+ 右上角价格（小字 13px）。整张卡片可点击跳转原详情页。少于 2
条数据时仍按 1 列显示，避免空白。
```

## C7. 待办页加拖拽排序

```
在 src/pages/TodoPage.tsx 的「未完成」和「今日」分段里，加
长按拖拽排序（按住右侧拖拽手柄 300ms 触发，不影响长按进入
编辑的判定）。拖拽时整张卡片半透明 + 上抬阴影，松手落位。
排序信息存到 localStorage 'todo.order'：[id1, id2, id3, ...]，
进入页面时按这个顺序排序。每次 create/update/delete 后重新
写入。已完成的 tab 不支持拖拽。
```

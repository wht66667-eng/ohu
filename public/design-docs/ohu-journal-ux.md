# 哦狐我的手账 · 纸页日记与日记锁 UX 实施计划

日期 2026-11-12（北京时间）。交付阶段为设计方案与概念图，供实现前评审。

## 1. 现状与目标

当前的「写日记」用弹层同时显示类型、日期、标题、心情、正文和照片选项，正文只占一块输入框。新条目已经用本地日期初始化，但日期仍作为必填感较强的表单项出现。历史日记和随手记以混合卡片展示，正文和照片存入同一套按账号区分的 IndexedDB，当前无日记密码锁。App 普通页面目前使用短淡入。相关入口见 [日记界面](../../项目源码/src/pages/campus/CampusJournal.tsx)、[手账存储](../../项目源码/src/lib/campus-journal.ts)、[App 现有进场效果](../../项目源码/src/components/RouteLoading.tsx)。

改动从「校园生活 → 我的手账」进入。日记采用整页纸面，随手记保留快速编辑入口。App 的主要内容页采用同一套书页运动语言，日记翻阅保留更明显的纸角、卷边和页缝阴影。

## 2. 页面与交互

| 场景 | 主要动作 | 细节 |
| --- | --- | --- |
| 我的手账 | 写今天、翻阅日记、随手记 | 写今天放在拇指易触区域。日记加锁时显示闭合封面和「解锁日记」。随手记有独立入口。 |
| 写日记 | 点击纸面开始、添加照片、完成 | 一张延伸到屏幕底部的暖白横线纸，顶部日期章，正文直接写在纸上。点击纸面再唤起键盘。选填标题、心情和引用学习记录收进工具区。 |
| 回看日记 | 上一篇、下一篇、按日期找 | 日历只在解锁后显示，选日期打开对应条目。同一天多篇按创建顺序展示，列表的置顶与搜索保留。读页与写页共用纸张视觉。 |
| 解锁日记 | 输入独立密码、显示或隐藏密码、解锁 | 底部弹层覆盖闭合封面。取消回到封面。错误时就地提示并保留焦点。解锁后打开刚才想看的页。 |
| 设置日记锁 | 设置、立即锁定、修改或关闭密码 | 设置时输入两遍独立密码。修改或关闭前验证当前密码。锁定状态仅显示通用提示。 |

### 纸张和写作手感

- 暖纸底色建议 `#FFF7E9`，墨绿正文 `#214B38`，浅灰绿横线和低饱和粉色左边线。纸纤维、页边阴影和卷角优先放在空白边缘，正文阅读区保持平整。正文用易读的系统中文字体，日期可用有书写感的字形。
- 首次进入提供一行可消失的占位「今天发生了什么？」。正文行高与横线使用同一布局参数，输入法换行、系统字体放大和长文滚动时持续对齐。纸面上的字由真实文本输入承载。
- 键盘打开时，正文随光标滚动。相机、照片、现有表情键盘和「完成」贴近键盘上沿，保留常用操作的触控面积。复用现有图片裁剪、滤镜、排序和每篇最多 9 张照片的能力。
- 打开新页时按设备本地日历自动盖日期章，显示日期与星期。保存日记所属日期、创建时间和写入时区。跨零点、切换时区、编辑旧文时保留原页日期。补记通过日期章选日期。
- 输入暂停后自动保存草稿，顶部显示「正在保存」「已保存」或「保存失败 · 重试」。空白页不生成记录。「完成」等待保存结果再退出。保存失败留在原页，返回时提供重试或明确放弃。

### 翻页手势和 App 切换

- 日记阅读区提供「上一篇」「下一篇」以及横向轻扫，向左看下一篇，向右看上一篇。页角先抬起，再带阴影掀开。翻过一篇后更新焦点与读屏日期提示，快速重复操作只完成一次。纵向滑动仍滚动正文。
- App 普通内容页采用约 240–320 ms 的轻量书页过渡，前进和后退方向相反。保留底栏、原有返回行为和滚动位置。日记阅读页采用约 340–460 ms 的纸页翻动，低端设备优先保持手势跟手。
- 基于现有 React Router 的 H5 和原生路由入口实现，不依赖官网多文档导航动画。加载慢时继续显示现有加载状态，等目标页可用再呈现过渡。
- 键盘输入、选图、编辑手势、系统边缘返回和弹层关闭优先由原交互处理。用户开启「减少动态效果」时，直接切换。锁定、退出账号和进入密码层时立即撤下日记内容，敏感画面不进入翻页快照。

## 3. 日记锁与数据规则

### 使用规则

1. 日记锁只用于「日记」。启用后，查看、编辑、搜索、预览或导出任一已保存日记，都需要密码解锁。包括当天已结束的日记。
2. 锁定时仍可点「写今天」打开空白纸。新建内容可以写入加密草稿。关闭后继续编辑同一篇草稿时需要解锁，防止从「写今天」绕回已保存内容。同一天可以新建多篇。
3. 解锁只在本次手账会话有效。离开手账、App 进入后台、账号切换、主动上锁或达到空闲时限时收起历史页。首版空闲时间拟为 5 分钟，真机验收时根据实际体验确认。相机或选图返回后若会话失效，重新解锁才恢复旧日记。
4. 日记密码与校园密码独立。设置时明确说明忘记密码无法找回旧日记。改密、关闭锁、明文导出都在解锁后由用户主动操作。备份优先提供加密文件，普通导出由用户明确选择。

### 存储设计与验证

- 以账号为单位区分锁配置和条目。启用后，日期、标题、正文、心情、照片和缩略图使用认证加密存入本机。外层仅保留分区键、不透明条目标识和版本信息。解锁后在内存建搜索索引。深链接、图片预览和导出入口走同一状态检查。
- 为实现「能写今天，锁着也不能读旧页」，拟采用公钥封装每条记录的随机数据密钥，记录与附件使用 AES-GCM。公钥可用于写入，私钥由日记密码派生的密钥加密保护。密码和解锁密钥只在会话中使用。候选方案用现成 Web Crypto RSA-OAEP 和经验证的密码派生库。Argon2id 参数和目标 WebView 性能先用 Android、iOS 真机验证后定稿。参考 [W3C Web Cryptography](https://www.w3.org/TR/webcrypto/) 与 [RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html)。
- 同一篇连续保存采用有序写入。完成按钮、后台切换和账号切换要等待已提交保存，迟到的回调不能恢复上个账号或已锁会话的内容。锁定清理内存搜索索引、预览对象 URL 和当前历史页，并通知其他打开的哦狐页面。
- 迁移按账号处理，兼容旧版单图和多图记录。先写入加密记录并逐条核对，全部成功后在同一切换事务中更新锁状态并删除明文条目。迁移中断保留可恢复进度并提示用户。系统任务切换器的隐私遮盖单独在 Android 和 iOS 真机核验。

## 4. 开源参考与采用方式

- **Mini Diary** 的少控件写作和独立日记密码适合作交互参考。仓库已归档，因此只参考界面取舍。 [Mini Diary 仓库](https://github.com/samuelmeuli/mini-diary)
- **Fenmark（Mini Diarium 后续项目）** 的输入即保存、按日期翻阅和主动锁定适合作为流程参考。对应到哦狐的是纸页草稿、日历找页和独立日记锁。 [Fenmark 使用说明](https://github.com/fjrevoredo/mini-diarium#quick-start)
- **jrnl** 会给未指定日期的内容写入当前日期和时间，并支持补记与日期检索。对应到哦狐的是自动日期章、补记入口和解锁后按日期搜索。 [jrnl 日期与搜索说明](https://jrnl.sh/en/latest/usage/)

以上采用交互与数据思路。概念图为哦狐独立设计。

## 5. 实施顺序与验收

| 顺序 | 可验收交付 | 验收要点 |
| --- | --- | --- |
| 1 | 纸页编辑与自动日期 | 正文直接输入。连续写、回车、改日期补记、跨零点和失败重试可完成。原生中文键盘和内置表情键盘均可操作。 |
| 2 | 历史读页、翻页与日期查找 | 上下篇按钮、轻扫、日历和返回键可用。纵向滚动与图片预览手势互不抢占。边界页有明确的禁用状态。 |
| 3 | 日记锁、加密草稿与迁移 | 锁定后从列表、搜索、直达链接、预览、导出和 App 切换器均无旧日记内容。错密、改密、后台、账号切换、迁移失败可重复验证。照片内容也纳入加密。 |
| 4 | App 通用翻页与真机联调 | 首页、课表、校园生活、手账进出与系统返回在 Android、iOS 安装版验收。低性能、冷启动、弱网、减少动态效果和键盘展开都可正常操作。 |

课表查询 · 江苏海洋大学（独立版）
==================================

【功能】
登录正方教务系统查询个人课表，周视图展示：
- 验证码登录（点击验证码图片可刷新）
- 周次切换、周一~周日排布
- 连续多节的同一门课自动合并显示
- 完全独立运行，不依赖校园生活 H5 主站

【运行环境】
Python 3.9 及以上

【首次使用】
在本目录打开命令行（cmd 或 PowerShell），执行：
    pip install -r jou-api/requirements.txt

【启动】
    python jou-api/app.py
然后浏览器打开：http://127.0.0.1:8090

【测试模式】
不连真实教务、返回样例数据（用于演示）：
    MOCK=1 python jou-api/app.py    （PowerShell：$env:MOCK="1"; python jou-api/app.py）

【说明】
- 默认端口 8090，可用环境变量 PORT 修改
- 验证码会话 3 分钟内有效，过期自动刷新
- 教务密码仅用于本次登录查询，不保存
